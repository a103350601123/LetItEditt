Frequently Asked Questions

Short answers about how LetitEdit works, how your data is handled and how the tool registry supports future expansion. Questions expand on click or with the keyboard.

Using the tools

Do the tools upload my text or files?

No. Every published LetitEdit tool processes input locally in your browser. Text you paste and files you choose are not sent to a LetitEdit server for processing.

Do I need an account?

No account, sign-up or subscription is required. Every tool is free to open and use.

Can I use the tools on a phone?

Yes. The interface is responsive from small 320px screens through large desktops, and the same processing runs on mobile browsers.

Privacy and safety

Is my input stored after I close the page?

Tool input is held in browser memory while the page is open. Copy, download and restoration actions only happen after you click them. Check the Privacy Policy for full details.

Are the redaction tools guaranteed to find all sensitive information?

No. Detection uses conservative patterns for common formats. Always review redacted output manually before sharing it, and treat restoration keys as sensitive because they contain the original values.

Adding tools

How are new tools added?

Tools are registered in a central data file with metadata such as name, category, slug, keywords and SEO fields. The navigation, counts, search, sitemap and category pages update automatically from that registry.

Why are some categories empty?

All planned categories exist now so the navigation and routes are stable. Tools appear in a category only after they are implemented and tested; placeholder tools are never published.
