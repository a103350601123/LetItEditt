How to use Screen Recorder

  1. Choose whether to capture a tab, a window or the whole screen when the browser asks.
  2. Turn on microphone audio if you want narration; leave it off for a silent recording.
  3. Confirm the live preview shows the right surface, then start recording.
  4. Use pause and resume to skip private moments or long waits.
  5. Stop the recording and review the preview and duration.
  6. Download the WebM file; nothing is uploaded by the recorder.

In-depth guide

A recorder that keeps the capture local

Screen recordings are often the quickest way to explain something that is hard to describe in text: a confusing menu, a bug that only appears in one browser, or a short walkthrough for a colleague. This recorder starts with a browser permission prompt and then captures the tab, window or screen you choose. A live preview shows the same surface the encoder sees, so you can confirm the selection before you talk through your steps. Microphone audio can be included or left off. When you stop, the file is assembled and downloaded on your device; no copy is sent to LetitEdit. That makes the tool suitable for recordings that contain private information, provided you remember to pause or stop before anything sensitive appears on screen.

Choosing what to capture

The browser, not this page, decides which surfaces are available. In a typical desktop browser you can pick a single tab, an application window or the whole screen. A tab capture is usually the cleanest choice for a web demo because notifications and unrelated windows stay out of the frame. A window capture is useful for a desktop application, while full screen is best when you need to move between several programs. Whatever you choose, check the preview. Dark or empty preview areas are a sign that the surface is not being captured as expected. You can cancel the prompt and start again; there is no penalty for a false start. Also close or minimise anything you do not want in the recording before you begin, because the tool captures pixels rather than understanding which windows matter.

Audio, pause and live preview

Narration is optional. If you enable microphone audio, the browser asks for microphone permission separately from screen permission, and you should speak at a normal level while watching the preview meter if one is shown. System audio is a different matter: support varies by browser and platform, so tab audio may be shareable in one setup and unavailable in another. The pause control is worth using generously. It stops new frames being added while you wait for a page to load, check a message or find the next file, which keeps the final video shorter and easier to watch. Pausing is not editing and does not remove anything already recorded. The live preview remains the best quality check throughout: if the picture freezes, the wrong window is selected or audio is missing, stop and restart rather than hoping the final file will be different.

Saving and using the WebM file

Stopping the recording finalises the capture and produces a WebM download. WebM is a common container for video encoded in the browser, and current browsers generally play it without conversion. File size grows with duration, resolution and motion, so a long screen capture can be surprisingly large; pausing during idle time helps more than almost any other setting. If you need a different container or a shorter clip, download first and then use a separate conversion or trimming tool. The recorder does not re-encode into a fixed list of presets, because available encoders differ between browsers. Before you rely on the file, play the download once outside the tool to confirm that the picture and any audio are present. If the file will not open, try a different browser for the next recording.

Limits, privacy and mobile browsers

Everything runs through the browser's screen capture API, which means the tool inherits both its strengths and its limits. It cannot record something your browser will not share, it cannot add a webcam overlay, and it cannot guarantee a particular frame rate on a busy machine. Mobile support is especially uneven: some mobile browsers offer no screen capture to websites, and others restrict capture to a single tab. When the API is unavailable, the page says so plainly instead of offering a fake recording. Privacy is straightforward: capture and encoding stay on your device, and closing or reloading the tab discards the in-memory video. Download the WebM before you leave the page. Keep the tab active during a recording, since some browsers throttle or interrupt capture when the tab is hidden for a long time.

Frequently asked questions

Does the recording leave my device?

No. The browser captures the chosen surface and encodes it locally, and the download is written straight to your device. LetitEdit does not receive the video, and there is no account, upload queue or remote storage.

Will this work on my phone?

Possibly, but many mobile browsers do not expose screen capture to web pages, and those that do may limit it to the current tab. If your browser offers no capture option, there is nothing the tool can record; try a desktop browser instead.

Can I record system audio or just my microphone?

Microphone audio is supported. System audio depends entirely on the browser and operating system: some let you tick a box to share tab audio, others do not. The recorder cannot force audio that the browser refuses to provide.

Why does the browser show a permission prompt?

Screen capture is deliberately guarded by the browser. You must choose what to share and confirm each recording session. If you dismiss the prompt or pick the wrong surface, stop and start again; the live preview shows what is actually being captured.

What format is downloaded, and can I edit it?

WebM, which is a common format for browser-recorded video. It plays in most current browsers and can often be trimmed or re-encoded elsewhere. Export options depend on what your browser can encode, so the download uses a supported WebM configuration rather than a fixed preset.

What happens to the recording when I close the page?

The in-memory recording is discarded. Download the file before you navigate away or reload. Pausing does not save anything permanently; it simply stops adding frames until you resume.
