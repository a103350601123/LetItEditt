Merge PDF, Word and Excel files

The LetItEdit file merger joins several files of the same type into one. You decide the order with position numbers.

Open the file merger

What you can do

  • Merge PDF files into one PDF
  • Merge Word (.docx) files into one document
  • Merge Excel and CSV files into one workbook
  • Choose the order with a position number for each file
  • Save in the format you choose

How to use it

  1. Add the first file and give it position 1.
  2. Add the next file and give it position 2, and so on.
  3. Press Merge and download.

Frequently asked questions

Can I merge a PDF and a Word file?

Files must be the same type. Convert one of them first with the file converter.

Is the order of the files kept?

Yes. Files are merged from the lowest position number to the highest.

Is my file uploaded?

No. Merging happens in your browser.
