How to use Image Resizer

  1. Open a PNG, JPG or WebP image from your device.
  2. Enter the target width and height in pixels.
  3. Keep aspect ratio locked to scale proportionally, or unlock it for an exact box.
  4. Choose Fit to contain the image or Stretch to fill the dimensions.
  5. Review the preview and download as PNG, JPG or WebP.

In-depth guide

What resizing actually does

Resizing changes the number of pixels in an image rather than cropping its content. You supply a target width and height, and the tool draws the source at that size, then writes a new file. This is useful for preparing avatars, product photos, email signatures, web headers and screenshots that must meet fixed dimension rules. Everything happens in your browser: the file you open is decoded locally, the new pixels are calculated locally, and only the finished download leaves the page. No account, upload queue or remote processing is involved. The preview lets you compare the new size with the original before you commit to a download. You can repeat the process with different values until the preview looks right.

Entering exact dimensions

Width and height are entered as whole pixel values. The original dimensions are shown so you can scale by a known factor, for example halving a 1600 by 1200 photo to 800 by 600. With the aspect ratio locked, changing one field updates the other to keep the same proportions. That is the safest option for photographs because it avoids squashed faces and oval circles. If you need an exact canvas size, unlock the ratio and enter both values. Remember that a resize changes pixels, not the framing: the whole picture is kept, so a wide photo placed in a narrow box is scaled down rather than cropped. Write down the original dimensions if you may need to restore them later.

Aspect ratio lock, fit and stretch

When the aspect ratio is locked, the image scales proportionally to the requested width or height. When it is unlocked, two modes decide how the picture fills the target box. Fit scales the image as large as possible while keeping every edge inside the dimensions, which may leave unused space along one side. Stretch maps the source directly onto the requested width and height, filling the box but changing proportions if they differ from the original. Use Fit for layouts where empty space is acceptable and Stretch only when a slight distortion is harmless, such as a background texture. Check the preview at both settings before deciding. A narrow column or a wide banner often needs different choices.

Formats and quality trade-offs

The download can be saved as PNG, JPG or WebP. PNG keeps pixels lossless and preserves transparency, which matters for logos and cut-outs. JPG is compact and widely supported but discards detail on each save, so use it for photographs without transparent areas. WebP offers smaller files with transparency support. Resizing itself interpolates pixels, and encoding can add further change, especially when the source is PNG and the output is JPG. Export once from the version you like instead of resizing repeatedly, because each round adds another generation of compression. Match the format to where the image will be used. Transparent areas also need a format that can store them. Check the file size after each export.

Upscaling and the pixel cap

You can enter values larger than the source, but enlargement cannot invent detail. The browser fills in new pixels by interpolating nearby ones, so an upscaled photo looks soft and may show visible blocks at high zoom. A small icon enlarged to a banner will rarely look sharp. Downscaling usually looks better, particularly when the source has plenty of detail. To keep output manageable, width and height are each capped at a documented maximum; requests above that limit are rejected with a clear message. If you genuinely need a huge print, use a dedicated desktop editor rather than stacking browser resizes. The cap is shown in the tool so you know the limit before you start.

Workflow, privacy and fixes

Open an image, enter the target size, choose the ratio and fill mode, then review the preview before downloading. Names and settings are not saved after the page closes, so a reload resets the tool. No image data is uploaded, but a shared screen, clipboard or download folder can still expose a private picture. If nothing happens after you click download, confirm both dimensions are positive numbers and within the cap, and wait for a large source to finish drawing. If the result looks distorted, re-lock the aspect ratio or switch from Stretch to Fit. If the file appears unchanged, check that you are opening the downloaded version rather than the original thumbnail.

Frequently asked questions

Is my image uploaded to resize it?

No. The resizing happens in your browser using the file you open. No copy is sent to a server, and the working image is cleared when the page closes.

What is the maximum output size?

Width and height are each capped at a documented limit to protect browser memory. Requests above that limit show a clear error; for a larger result, use a desktop editor or work in stages.

What happens when I unlock the aspect ratio?

Unlocked mode lets you set any width and height. Fit scales the image to stay inside that box, which can leave empty space, while Stretch changes the proportions to fill it exactly and may distort faces or circles.

Can I enlarge a small photo without blur?

You can enter dimensions larger than the source, but the browser can only interpolate existing pixels. Upscaling looks soft and cannot create new detail that was never captured.

Why did my download keep the original size?

Check that you applied the resize before downloading and that both values are positive numbers within the allowed cap. A very large source may take time to process, so wait for the preview to update. Reloading also resets settings.
