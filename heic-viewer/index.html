In-depth guide

Why HEIC needs a real decoder

Photos from many modern phones are saved in HEIC or HEIF format, which uses more efficient compression than JPEG. That efficiency is useful on a device with limited storage, but it also means a browser cannot simply display the file the way it displays a JPEG. This viewer loads a libheif decoder library locally and uses it to turn each file into pixels the page can show. The result is a genuine preview generated from your photo, not a placeholder or an icon. If decoding fails, the tool says so plainly instead of inventing a successful result. You can then decide whether to retry, convert the file on the source device or use the successfully decoded images in the batch. If you depend on these pictures regularly, keeping the original files alongside converted copies saves you repeating the step later.

Viewing a single photo

For one image, choose the .heic or .heif file and wait for the decoder to finish. A thumbnail appears once the file is read, and selecting it opens a larger preview. This preview is useful for checking orientation, colour and whether the photo you picked is the one you wanted before you spend time downloading a converted copy. HEIC stores more than just pixels — some files carry depth maps, live-photo pairs or multiple representations — and the viewer shows the primary still image. Extra payloads are not exposed as separate downloads. If the preview looks empty or the status area shows an error, the decoder could not interpret that particular file; the page will not quietly present a blank image as a success. Try another file to confirm the viewer itself is working before you investigate the source.

Converting a batch

Batch mode is the practical choice when you have moved a folder of photos off a phone. Select several files at once and the viewer decodes them one by one, listing a thumbnail for each success and an error for each failure. Choose PNG or JPG for the downloads. PNG keeps the decoded pixels without further loss and is a good fit for graphics or images with sharp edges, while JPG produces smaller files that are easier to email or upload. Mixed results are normal: a folder can contain both standard HEIC files and variants that the current decoder cannot handle. Failed items are reported by name so you can deal with them separately instead of wondering which conversions quietly disappeared. Work through the failures after the successful files are downloaded.

Formats, quality and file size

Converting HEIC to PNG or JPG is a change of container and compression, not an enhancement. The decoder reconstructs the pixels that were stored in the HEIC file; the encoder then writes them into the format you chose. PNG preserves those pixels exactly and can produce a large file, especially for a high-resolution phone photo. JPG compresses again, which reduces size but can introduce slight softness around fine detail. Neither format restores motion in a live-photo pair or reveals detail that was never captured. If you need a smaller result for a website, convert first and then resize or compress with a dedicated tool. Keep the original HEIC file as your master copy so you can re-convert later with different settings.

Privacy and troubleshooting

All decoding and encoding happens in your browser. The viewer uses a locally loaded libheif library, and your photos are not uploaded to LetitEdit or to a third-party conversion service. That is reassuring for personal pictures, but it also means the page depends on your browser's capabilities. Very large batches can be slow, so keep the tab active and wait for each status message before leaving. If a file fails, check that the extension really is .heic or .heif, then try re-exporting it from the source device as JPEG and see whether that copy opens. Older browsers may lack features the decoder needs; updating the browser often fixes unexplained failures. Should the page become unresponsive, reload it and process the photos in smaller groups.

Frequently asked questions

Are my HEIC photos uploaded to a server?

No. The viewer loads a libheif decoder library locally and decodes files in your browser. Your photos are not sent to LetitEdit or to any conversion service.

Why won't my file open?

HEIC files can use different codecs and some variants are not supported by the current browser decoder. If decoding fails, the tool reports the failure rather than showing a blank or fake preview. Try exporting the photo as JPEG from the source device.

Can I convert many files at once?

Yes. Batch mode accepts multiple .heic and .heif files, shows a thumbnail for each decoded image and lets you download PNG or JPG copies. Files the decoder cannot read are listed as failures instead of being silently skipped.

Which output format should I choose?

PNG is lossless and keeps the decoded pixels exactly, which suits screenshots and graphics. JPG is smaller and is usually better for photographs. Neither adds information that was not in the original HEIC file.

Why does conversion take a while?

HEIC uses efficient compression, so decoding is more work than opening a JPEG. A batch of high-resolution photos can take noticeable time even on a fast machine. Keep the tab active and wait for the status message before downloading.
