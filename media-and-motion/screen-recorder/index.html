    Guide

    What this screen recorder does

    A screen recorder captures what happens on a display and saves it as a video file. This tool uses the browser's own Screen Capture API to ask which screen, application window or browser tab you want to share, then records that stream with MediaRecorder. You can add a microphone, system or tab audio, and a webcam overlay before you start.

    The recorder is intentionally narrow: it records, previews and downloads. It is not a video editor and does not add filters, cuts, transitions or subtitles. If you need to trim the result or combine it with other clips, open the Video Trimmer or the Professional Video Editor after downloading.

    How to record your screen

    1. Choose your settings. Pick a resolution, frame rate and quality. Original resolution is the safest choice because the source is never enlarged.
    2. Select audio. Leave system or tab audio on if you need sound from the shared source. Enable Microphone and choose the right device if you want narration.
    3. Add a webcam if you want one. Enable Include webcam, allow camera access, then position and size the overlay. The webcam is burned into the final recording.
    4. Click Start recording. The browser opens its own sharing dialog. Choose Entire Screen, Window or Chrome Tab. This page cannot choose for you and cannot bypass the permission prompt.
    5. Record, pause or stop. The timer and REC badge show that capture is live. Pause hides the paused time from the file; Resume continues the same recording; Stop finishes and prepares the download.
    6. Preview and download. Check the preview, the measured duration, size and resolution, then download the real file. Record again discards the current take and starts clean.

    How to record a browser tab

    In Chrome and Edge, choose Chrome Tab (or the equivalent tab option) in the browser dialog, then pick the tab. When the system audio option is available, enable Share tab audio in the same dialog. Tab audio is the most reliable way to capture sound from a browser page because it does not depend on the operating system's loopback device.

    If you record a tab that is playing video, keep that tab open and audible for the whole take. Switching the tab to mute, pausing the media or closing it ends the sound but not the screen capture. Some browsers stop the whole capture when the shared tab is closed; in that case the tool keeps everything recorded up to that point.

    How to record microphone audio

    Enable Microphone before you start. The first time, the browser asks for microphone permission. Pick a device from the microphone list and adjust the volume slider; the level meter shows the mixed signal that is being recorded. If you enable both system audio and microphone, the Web Audio API mixes them into one track with a small headroom trim so a loud source does not clip.

    If you deny microphone permission, the recording still continues with system audio or no audio, and the page tells you what happened. Use the Mute mic button during a recording to silence the microphone without losing it; the button toggles back to Unmute. Microphone tracks are stopped when the recording ends.

    How to use the webcam overlay

    Enable Include webcam, allow camera access and check the preview. Choose one of the four corners, drag the size slider and pick a circle or a rounded rectangle. The preview uses the same geometry as the recorded composition, so what you see is what the file contains.

    When the webcam is enabled, the screen and camera are drawn into a canvas and the canvas stream is recorded. That is why the overlay survives the download instead of disappearing. Keep the recorder tab visible during this mode: browsers pause animation in hidden tabs, which can reduce the composition frame rate. Webcam audio is never captured on its own; enable Microphone if you want the camera microphone to be heard.

    Supported formats and real limitations

    The page checks MediaRecorder.isTypeSupported() before offering a recording format. Chromium-based browsers and Firefox typically produce WebM with VP9 or VP8 video and Opus audio. Some Safari versions can produce a genuine MP4 with H.264 and AAC. The download extension always matches the actual bytes; a WebM file is never renamed to MP4, and no conversion is attempted.

    • No upscaling. A 720p source is not enlarged to 1080p. Live screen tracks also cannot always be resized by the browser; the actual captured size is displayed.
    • System audio is conditional. It depends on the browser, operating system and the source you share. The page cannot add an option that the browser does not offer.
    • Frame rate is a request. The browser and the shared application decide what is actually delivered. The recorder reports the measured composition rate when it can.
    • Mobile support is limited. Most mobile browsers do not expose screen capture at all. The page detects a missing API and explains that a desktop browser is required.
    • Long takes use memory. MediaRecorder holds the recording until you stop. Very long or high-resolution takes can exhaust memory on small devices.

    Privacy and local processing

    The screen, microphone and camera streams are read directly by this page. The recording is assembled in memory with MediaRecorder and offered as a local blob download. Nothing is sent to LetitEdit or any third party, there is no account and no paid API. The page does not store recordings on a server or in remote storage.

    When you stop, cancel or leave the page, the capture tracks are stopped and the camera and microphone are released. Object URLs are revoked when a take is discarded or replaced. Closing the tab ends every stream immediately.

    Troubleshooting

    • The sharing dialog does not appear. Use a supported desktop browser, open the page over HTTPS or localhost, and make sure another screen-sharing application is not holding the display.
    • I denied permission by mistake. Click Start recording again. Browser dialogs often do not show a permanent block for screen capture; if they do, reset the site permission in the browser's address bar.
    • There is no system audio option. Share a browser tab with tab audio enabled, or share an entire screen on Windows with Chrome or Edge. macOS and some Linux setups do not offer system audio through the browser.
    • The microphone is silent. Check the device selection, the operating system input level and the Mute mic button. A recording with an included but silent track is labelled "no sound detected" rather than claimed as working audio.
    • The webcam is missing from the file. Make sure Include webcam was enabled before you clicked Start. The camera is only requested when you enable it, and the overlay is burned into the canvas recording.
    • Screen sharing stopped by itself. Closing the shared window, unplugging a display or clicking Stop sharing ends the track. The recorder stops cleanly and keeps the material captured so far.
    • The download does not open. The file uses the format your browser actually recorded. Try VLC or another player, and use the other browser format if your editor does not accept WebM.

    Frequently asked questions

    Is the screen recording uploaded anywhere?

    No. The screen, microphone and webcam streams stay in your browser tab. The recording is written by MediaRecorder on your device and downloaded directly from a local blob. There is no upload, no account and no server-side copy.

    Can I record system audio or browser-tab audio?

    It depends on the browser and operating system. Chrome and Edge on Windows can offer system audio when you share a screen, and Chrome can offer tab audio when you share a tab. The browser decides which audio options appear in its sharing dialog, and this page cannot force an option the browser does not provide.

    Which file format will I get?

    The page detects the formats MediaRecorder genuinely supports. Chromium-based browsers and Firefox usually produce WebM with VP9 or VP8 video and Opus audio. Some Safari versions can produce MP4 with H.264 and AAC. The download extension always matches the real bytes, and WebM is never renamed to MP4.

    Does the webcam appear in the final recording?

    Yes. When the webcam is enabled, the screen and camera are drawn into a composition canvas and the canvas stream is recorded, so the webcam overlay is part of the downloaded file, not just a preview.

    Can I use the screen recorder on a phone?

    Most mobile browsers do not implement screen capture with getDisplayMedia. If the API is missing the page explains that and recommends a supported desktop browser. Some Android and iOS versions may not offer any screen-capture choice at all.

    What happens if I click Stop sharing in the browser?

    The tool detects the ended capture track, stops the recorder and keeps everything captured so far. It then shows the normal preview and download controls.

    Is there a time limit or a risk with long recordings?

    There is no fixed time limit, but MediaRecorder keeps the recording in memory until you stop. Very long or high-resolution recordings can use a lot of memory and may fail on devices with limited RAM. Shorter takes and a lower resolution are safer.

    Why is my microphone or webcam not working?

    Check the site permissions in your browser, make sure another application is not using the device, and choose the right microphone. If you deny the microphone, the screen recording continues without it; if you deny the camera, the recording continues with the screen only.
