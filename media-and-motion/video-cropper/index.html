Guide

What video cropping means

Cropping keeps a rectangular part of each video frame and discards the rest. The kept region can be a square for a social post, a vertical slice for a phone screen, or a wide band that removes the top and bottom of a clip. The picture inside the crop is not squeezed or stretched; it is cut out and encoded as a new frame.

This is different from hiding part of a player with a CSS mask. A visual crop that only changes the preview would still export the full original frame. This tool decodes every frame, draws the selected region onto an output canvas, and encodes that result, so the downloaded file contains only the crop you chose.

How to crop a video in your browser

  1. Add one video. Drag a file onto the upload area or choose Browse video. MP4, M4V, MOV, WebM and MKV files are accepted when this browser can decode them.
  2. Place the crop frame. Drag the frame to move it. Drag a corner or edge to resize it. The dimmed area is what will be removed.
  3. Pick a shape. Use Original to keep the source ratio, Freeform for any rectangle, or a preset such as 16:9, 9:16, 1:1, 4:3, 3:2, 2:3, 4:5 or 5:4. A preset locks the shape while you reposition the frame.
  4. Check the exact numbers. X and Y set the top-left corner. Width and height set the crop size. Invalid values are rejected with an explanation instead of being silently changed.
  5. Preview the crop. Switch to Preview crop and play the video. The preview shows only the region that will be exported, including rotation metadata.
  6. Choose the output. Keep the crop's own pixel size, use 1080p, 720p or 480p, or enter a custom size. The output shape always follows the crop.
  7. Export and download. The page reports real progress, allows cancellation, verifies the resulting file, and then offers a local download.

How aspect ratio presets work

An aspect ratio is the relationship between width and height. 16:9 is wide, 9:16 is tall, and 1:1 is square. Selecting a preset adjusts the crop rectangle to that ratio and fits the largest possible rectangle inside the source frame. You can then move the rectangle anywhere inside the video without changing its shape.

If the source is already the selected ratio, the crop can cover the whole frame. If the source is a different shape, the crop must be smaller in one direction. For example, a 16:9 preset on a portrait video uses the full width and a much shorter height. The page explains this instead of stretching the image to fill a shape it does not have.

Original uses the uploaded video's real display aspect ratio, including rotation. Freeform removes the ratio lock so each edge can move independently. Presets do not change the source file and do not add black bars; they define which pixels are kept.

Cropping versus resizing

Cropping removes pixels around the selection. Resizing changes how many pixels represent the same picture. This tool does both in one export: it cuts the selected region, then scales that region to the output size you choose. The output keeps the crop's shape, so the image is never stretched to a different aspect ratio.

Scaling up cannot recover detail that the original camera did not record. Original crop size is the default because it avoids unnecessary enlargement. Choosing 1080p on a small crop, or entering a custom size larger than the crop, produces a bigger file but not more real detail. The output note tells you whether the export is upscaling, downscaling or staying at the crop's size.

Supported formats and browser limits

MP4, M4V, MOV, WebM and MKV inputs are accepted when the browser can decode their video and audio codecs. Current Chrome and Edge usually handle H.264/AAC MP4, VP8/VP9/Opus WebM and many MOV, M4V and MKV files. Firefox and Safari expose different codec sets, so the same file may work in one browser and fail in another.

Output is limited to MP4 and WebM. MP4 uses H.264 video and AAC audio; WebM uses VP9 video and Opus audio. The format selector is checked against the browser's WebCodecs encoders for the exact output size. A format that cannot be encoded at that size is disabled with an explanation instead of producing a broken download.

Encoders generally require even width and height. When a crop or custom size produces an odd number, the tool rounds that dimension to the nearest even pixel and says so. This changes the output by at most one pixel and does not alter the selected region.

Crop accuracy, rotation and audio

The crop frame is stored in the video's display coordinate system. The preview scales that system to the available width, and pointer movement is converted back into source pixels, so a crop stays correct when the window is resized or the page is used on a phone. The exporter uses the same coordinates after applying rotation metadata, which means the saved file matches the preview rather than the raw, unrotated frame.

Audio is decoded separately, normalized to 48 kHz stereo, and written alongside the cropped video with its original timing. A video without an audio track exports without one. If a file has audio that this browser cannot decode, the file is rejected with a clear message; the tool does not silently drop the sound. If the browser cannot encode the selected audio codec, that output format is disabled.

Cropping always re-encodes. A stream copy cannot remove pixels from every frame, so the High, Balanced and Smaller file options describe encoder quality, not a lossless mode. Re-encoding can make a file larger than the input, especially when the source was already heavily compressed.

Privacy and performance

The video is decoded, cropped, encoded and muxed inside a Web Worker in this tab using Mediabunny and the browser's WebCodecs implementation. The worker is loaded only after a video is added. It is terminated when you remove the video or leave the page, which releases decoder and encoder resources.

Files can be up to 2 GB, but that is a safety limit, not a promise that every device can process a file that size. Long or high-resolution videos need more memory. The page warns when a file is large or the output is very large. If an export fails, try a shorter video, a smaller output size, or close other memory-heavy tabs.

There is no upload, account, paid API or server-side copy. Temporary object URLs for the source and the result are released when you replace the video, start another crop or leave the page.

Frequently asked questions

Does the video cropper upload my video?

No. The video is decoded, cropped, re-encoded and muxed inside your browser tab. It is not sent to LetitEdit or to a third-party service, and no account is required.

Which video formats can I crop?

MP4, M4V, MOV, WebM and MKV are accepted when this browser can decode their video and audio codecs. Unsupported, corrupted or audio-only files are rejected with a clear message.

Does cropping change the video's aspect ratio?

The output uses the aspect ratio of the crop selection. Choosing 16:9, 9:16, 1:1 or another preset changes the crop frame, not the video by stretching. The cropped area is then encoded at the output size you choose.

Is the exported video lossless?

No. A real crop changes every frame and requires decoding and re-encoding. The High, Balanced and Smaller file options change the encoder quality target. The tool does not claim a lossless stream copy.

Why are the output dimensions rounded to even numbers?

Common video encoders require even width and height values. When a crop or custom size produces an odd value, the tool rounds it to the nearest even pixel and explains the change. The crop itself is not stretched.

Can I crop a portrait video to a landscape ratio?

Yes, as long as the requested ratio fits inside the source frame. A landscape crop of a portrait video uses the full width and a shorter height, so part of the picture is removed. The tool fits the largest matching region inside the frame.

Is the audio preserved?

Yes, when the browser can decode and encode the audio. Audio is normalized to 48 kHz stereo and keeps its original timing. If the audio cannot be decoded, the file is rejected instead of silently losing its sound.

What happens to videos with rotation metadata?

The preview and the crop overlay use the video's display orientation, including rotation metadata. The exporter applies the rotation before cropping, so the saved file shows the same region you selected and does not carry a misleading rotation flag.

Can I export a size larger than the crop?

Yes, with a preset or a custom size, but that upscales the image and cannot add detail. Original crop size is the default and avoids upscaling. The page tells you when the chosen output is larger than the crop.

Does the cropper work on phones?

The workspace is a single column on small screens and the crop handles have enlarged touch targets. Export speed depends on the phone's decoder and encoder support and on available memory.
