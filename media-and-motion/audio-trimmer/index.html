Guide

What audio trimming means

Trimming is the simplest edit you can make to an audio file: you choose a start point and an end point, and everything outside that range is removed. It is different from compression, which changes the bitrate, and from noise reduction or normalization, which change the sound inside the file. A trim changes the duration while keeping the audio that falls inside the range.

This tool keeps the selected section and discards the rest. The original file on your device is never modified. A new file is created in the browser and offered as a download, so you can trim the same source several times without losing anything.

How to trim audio

  1. Add a file. Drag an audio file onto the upload area or choose Browse audio. MP3, WAV, M4A, AAC, OGG, FLAC and WebM are accepted when this browser can decode them.
  2. Listen and find the section. Press Play, drag the seek bar, click the waveform, or use the keyboard shortcuts. The playhead follows playback.
  3. Set the boundaries. Drag the blue start and end handles, type exact times, or press Set to playhead. The selected duration updates as you move them.
  4. Preview the cut. Preview selection plays only the highlighted range. Turn on Loop preview to repeat it while you adjust the edges.
  5. Zoom when needed. The + and − buttons stretch the waveform horizontally. Use the scrollbar under the waveform, or a trackpad, to reach the part you are editing. Fit returns to the whole file.
  6. Export. Choose WAV or MP3, then press Trim and download. The tool shows real progress and only offers the download after the file has been written.

Waveform, handles and exact times

The waveform is drawn from the decoded samples, so quiet passages and loud peaks are visible before you cut. The shaded areas are outside the selection; the blue highlighted area is what the export will keep. The vertical line is the playhead.

The start and end fields accept HH:MM:SS.mmm, MM:SS.mmm or a plain number of seconds. Dragging a handle updates the matching field, and typing a time moves the handle. The end must be later than the start, the start cannot be negative, and neither value can pass the file's duration. An invalid value is marked and the export button stays disabled until it is corrected.

The handles work with a mouse, a trackpad, a pen and a touch screen. Arrow keys move a focused handle by 0.1 seconds, or by 1 second with Shift. Home and End jump the focused handle to the start or end of the file.

Supported formats and browser limits

The tool reads the file with the browser's own audio decoder. That means support depends on the browser and its codecs, not on a fixed server-side list. Current Chrome and Edge usually decode MP3, WAV, M4A/AAC, OGG/Opus, FLAC and WebM. Firefox and Safari expose different codec sets, so a format that works in one browser may be rejected in another. AIFF sometimes works. A corrupted file, a DRM-protected file or a codec the browser does not implement is rejected with a message instead of a broken result.

WAV is always the baseline output. MP3 is offered only when the local LAME encoder starts and the decoded audio is mono or stereo at 32 kHz, 44.1 kHz or 48 kHz. When MP3 is not available, the option is disabled and the page explains why; it is never renamed or offered as a format the bytes do not match.

Sample rate, channels and output quality

Before decoding, the tool reads the source sample rate and channel count from the file's container. It then asks the browser to decode at that sample rate, so a 44.1 kHz stereo source stays 44.1 kHz stereo in the WAV export instead of being silently converted to the browser's default rate. The rate actually used is shown in the file details and in the export summary.

WAV output is uncompressed 16-bit PCM. It is larger than the source MP3, but it is the most predictable result and needs no encoder beyond the browser. The selected samples are copied at audio-sample boundaries, so the cut is sample-accurate relative to the decoded audio.

MP3 output is a real LAME encode at the bitrate you choose. It is lossy and adds a short amount of encoder padding (often tens of milliseconds) at the start or end, so its playing time can differ slightly from the selected duration. The reported duration comes from the samples that were encoded, not from a guess. If you need the exact sample count, use WAV.

What this tool does not do

This is a trimmer, not a full audio editor. It does not remove a middle section and join the two remaining parts, add fades, normalize loudness, remove noise, change pitch or tempo, mix multiple tracks, or convert a whole video. Those jobs belong in separate tools. Keeping the scope narrow makes the trim workflow faster and the result easier to predict.

Privacy and local processing

Your audio is decoded, trimmed and encoded inside this browser tab. There is no upload, no account, no paid API and no server-side copy. Temporary object URLs are released when you remove the file, trim another section or leave the page. The export worker is closed when it is no longer needed, which releases its encoder buffers.

Very large files are limited by device memory rather than by a server quota. The page accepts files up to 500 MB, but a long recording can still exhaust memory on a phone. For the most reliable result, trim a shorter clip or close other memory-heavy tabs first. If decoding fails, the page says so and keeps the previous file intact.

Troubleshooting

The file will not load. The browser may not support its codec, the file may be corrupted, or it may be too large for the device. Try playing it in the same browser first, then convert it to WAV or MP3 elsewhere if needed.

The export button is disabled. The selection may be empty, a time field may be invalid, or an export may already be running. Correct the field or wait for the current export to finish.

MP3 is greyed out. The local encoder did not start, or the decoded file is not mono/stereo at a supported rate. WAV export still works and keeps the decoded sample rate.

The result is silent. Check that the selected range contains sound in the waveform and that the source file plays normally. A selection in a silent passage produces a silent file, which is the correct result.

Frequently asked questions

Does the audio trimmer upload my file?

No. The audio is decoded, trimmed and encoded inside your browser tab. It is not sent to LetitEdit or to a third-party service, and no account is required.

Which audio formats can I trim?

MP3, WAV, M4A, AAC, OGG, Opus, FLAC and WebM are accepted when this browser can decode them. AIFF may also work. A file the browser cannot decode is rejected with a clear message.

Does the WAV export keep the original sample rate and channels?

The tool asks the browser to decode at the source sample rate and writes uncompressed 16-bit PCM with the decoded channel count. The actual rate used is shown before and after export. If the browser cannot decode at that rate, it falls back to its own rate and says so.

Is MP3 export always available?

No. MP3 uses a local LAME encoder and is offered only when the encoder starts and the decoded audio is mono or stereo at 32 kHz, 44.1 kHz or 48 kHz. Otherwise the MP3 option is disabled and WAV remains available.

Is trimming lossless?

WAV export copies the decoded PCM samples in the selected range into a new 16-bit PCM file, so no additional lossy encoding is applied. MP3 export re-encodes the selection and is lossy, with a short amount of encoder padding.

Can I remove a middle section and join the rest?

Not in this version. The Audio Trimmer keeps the selected section and removes everything outside it. Removing a middle section would need a separate join workflow, so the option is not offered.

Does the tool work on phones and tablets?

Yes. The layout is responsive and the waveform handles are touch-friendly. Long files can still exhaust the memory of a phone, so shorter clips are the most reliable.

Is there a file size limit?

The input limit is 500 MB, but the practical limit is the memory available on your device. Very long files may fail to decode. The page reports the failure instead of producing a broken download.
