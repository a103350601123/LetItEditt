    Guide

    What an audio converter actually does

    An audio file is a container of encoded samples. Converting it means decoding those samples into raw audio, changing the sample rate or channel layout if you asked for it, and then encoding the result with a different codec or setting. Renaming song.wav to song.mp3 does not convert anything: the bytes stay WAV and most players will either reject the file or play silence. This tool performs the real decode and encode steps, so the extension, the MIME type and the contents agree.

    The original file on your device is never modified. The converted copy is created in memory and offered as a download. You can convert the same file several times with different settings, and the source stays untouched.

    How to convert audio files

    1. Add your audio. Drag files onto the drop area or choose Browse audio files. You can queue up to 20 files, and the list shows each file's detected format, duration and size.
    2. Pick an output format. MP3 is the most compatible lossy format. WAV and AIFF are uncompressed PCM. FLAC is lossless compression. M4A (AAC) and OGG (Opus) are efficient modern lossy formats.
    3. Set the quality. Choose a bitrate preset from 64 to 320 kbps for lossy formats, a sample rate, and mono or stereo. Irrelevant controls are hidden for WAV, AIFF and FLAC, which do not use a bitrate.
    4. Convert. Press Convert files. Files are decoded and encoded one at a time, and the progress bar reports real work rather than a timer.
    5. Download. A single file downloads automatically. For a batch, each row gets its own link and you can download everything as one ZIP archive.

    Supported input and output formats

    Input support comes from the browser. Current Chrome and Edge usually decode MP3, WAV, FLAC, OGG/Opus, M4A/AAC and WebM audio. AIFF is decoded by this page itself, because Chrome does not decode AIFF natively. Firefox and Safari expose different codec sets, so a file that works in one browser may be rejected in another. WMA is not supported: no current browser decodes it, and pretending otherwise would produce a broken file.

    Lossy and lossless: what you can and cannot get back

    MP3, AAC and Opus are lossy. They discard information that is hard to hear in exchange for a much smaller file. Once that information is gone, no converter can put it back. Decoding an MP3 to WAV gives you an uncompressed file that contains exactly the audio the MP3 already had; it does not add detail, and the file becomes much larger. That is still useful when an editor or a video tool insists on WAV, but it is not an upgrade in quality.

    WAV, AIFF and FLAC are lossless in the sense that decoding them returns the samples that were written. FLAC stores the same 16-bit samples as WAV in a compressed form, so it usually takes roughly half the space. Converting FLAC to MP3 is lossy; converting MP3 to FLAC is lossless in file terms but keeps the MP3's original lossy quality. The table above describes the format, not a promise about the source.

    This converter always decodes to samples before encoding. That means a lossy-to-lossy conversion such as MP3 to M4A involves two lossy generations, and the second one can remove a little more detail. When you have a choice, convert from the highest-quality source you still have, ideally a WAV, AIFF or FLAC master.

    Choosing a bitrate, sample rate and channel layout

    Bitrate is the amount of data used per second. For MP3, 64 kbps mono is common for speech, 96 to 128 kbps suits podcasts and casual listening, 192 kbps is a good general music setting, and 256 to 320 kbps is appropriate for critical listening. Higher settings are not harmful, but they quickly stop improving a source that was already compressed.

    Sample rate is how many samples are stored per second. 44.1 kHz matches CD audio, 48 kHz matches most video and modern recording interfaces, and 22.05 kHz halves the storage at the cost of everything above roughly 11 kHz. Converting 44.1 kHz to 48 kHz is a real resample; it does not add missing high frequencies. Auto keeps each file's own rate when the chosen format supports it, which avoids an unnecessary resample.

    Stereo stores two channels and mono stores one. Mono halves the size and is often enough for spoken word. Downmixing stereo to mono combines both channels, so a hard-panned instrument becomes quieter rather than disappearing. Opus output is fixed at 48 kHz because that is the rate the WebCodecs Opus encoder accepts; the page states this instead of silently pretending otherwise.

    Batch conversion and ZIP downloads

    A batch is simply several files queued with the same output settings. Files are converted one after another so that only one decoded file needs to be in memory at a time. Each finished file appears in the list with its output size and a download link. When more than one file is converted, the page also offers a ZIP archive; the ZIP is built locally and uses the store method, so it packages the files without re-compressing them.

    If one file in a batch fails, the rest still convert. The failed row keeps a clear error message so you can remove it and retry the others. Conversion can be cancelled between files and during encoding; a cancelled batch keeps any files that had already finished.

    Privacy, memory and practical limits

    There is no upload, no account, no paid API and no server-side copy. The page loads its own code and encoder libraries, reads your files through the browser's file picker, and creates downloads with local object URLs. Temporary URLs are released when you remove a file, clear the list, convert again or leave the page.

    The page accepts up to 20 files, 500 MB per file, 1 GB of input in total and 30 minutes per file. The real limit is device memory: a decoded stereo file at 48 kHz uses about 23 MB per minute as 32-bit floats, and encoding needs room for the output as well. On a phone, prefer shorter files and close other memory-heavy tabs. A file that is too large or too long is rejected with an explanation rather than freezing the page.

    What this tool does not do

    It does not repair corrupted files, remove noise, change pitch or tempo, normalise loudness, edit metadata tags, split tracks or record audio. It does not bypass DRM, and it cannot decode a codec the browser does not implement. Those jobs belong in other tools. Keeping the scope narrow makes the output predictable.

    Troubleshooting

    A file is rejected. The browser may not decode its codec, the file may be corrupt, or it may exceed the size or duration limit. Try playing it in the same browser first. WMA is not supported at all.

    M4A or OGG is disabled. The browser did not expose a working WebCodecs encoder for that codec. Chrome and Edge usually support both; some Firefox and Safari versions do not. MP3, WAV, FLAC and AIFF remain available.

    The output sounds worse than the source. A lossy output at a low bitrate, or a second lossy generation, removes detail. Raise the bitrate or choose WAV or FLAC if size is not the priority.

    The download did not appear. Some browsers block automatic downloads until you allow them for this site. Use the download link in the file row, or the ZIP button for a batch.

    The page is slow with long files. Decoding and encoding are real work. Close other tabs, convert fewer files at a time, and keep the tab in the foreground on mobile.

    Frequently asked questions

    Does the audio converter upload my files?

    No. Files are read, decoded, resampled and encoded inside your browser tab. Nothing is sent to LetitEdit or to a third-party service, and no account is required.

    Which formats can I convert from and to?

    Input depends on the browser decoder: MP3, WAV, AIFF/AIFC, FLAC, OGG/Opus, M4A/AAC and WebM audio usually work. Output is MP3, WAV, FLAC, M4A/AAC, OGG/Opus or AIFF. WMA is not supported.

    Does converting MP3 to WAV improve quality?

    No. Decoding an MP3 to WAV preserves what is already there and adds no new detail. The lost frequencies cannot be reconstructed. WAV is useful for editing because it is uncompressed, not because it sounds better than the original MP3.

    Is it safe to convert audio online here?

    The conversion runs locally, so your audio never leaves the device. The page loads its code and encoder libraries from the same site, does not use an upload endpoint and does not require an account.

    What bitrate should I use for MP3?

    For speech and podcasts, 64 to 96 kbps mono is often enough. For music, 192 kbps is a good balance, and 256 to 320 kbps is appropriate for critical listening or archiving. Higher bitrates cannot restore detail that a lossy source already lost.

    Can I convert several files at once?

    Yes. Add up to 20 files, choose one output format, and convert them in a single batch. Each finished file gets its own download link, and the whole batch can be downloaded as one ZIP archive.

    Why is M4A or OGG disabled?

    M4A/AAC and OGG/Opus output use the browser WebCodecs audio encoder. When the browser does not expose a working encoder for the selected rate and channel count, the option is disabled instead of producing a file with the wrong contents.

    Are the output files real conversions?

    Yes. Every output is decoded to samples, resampled and mixed when needed, and then encoded with the matching encoder. The tool never renames a file to pretend it is another format.

    Why does an M4A or OGG file last a few milliseconds longer?

    AAC and Opus encoders add a short priming or padding period at the start and end. The difference is normally around 10 to 25 milliseconds and is part of how those codecs work, not a sign that the audio was duplicated.
