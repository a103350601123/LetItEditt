Guide

What a real video converter does

Changing a file extension does not convert a video. A genuine conversion decodes the compressed frames back into pictures, optionally resizes them, encodes those pictures with a video codec, encodes the audio with an audio codec, and writes both streams into a new container. This tool performs that whole chain inside a Web Worker in your browser using Mediabunny and WebCodecs. Nothing is uploaded, and nothing is faked.

Because the work is real, the result panel reports measured facts: the container, the codec that was written, the encoded resolution, the duration, the file size and the bitrate read back from the finished file. If the browser cannot encode a combination, the option is disabled instead of producing a file that claims to be something it is not.

How to convert a video in your browser

  1. Choose a mode. Use Video to video to change container, codec, resolution or quality, or Video to audio to extract a soundtrack.
  2. Add one video. Drag a file onto the upload area or choose Browse video. MP4, M4V, MOV, WebM and MKV are accepted when this browser can decode them.
  3. Check the source details. The workspace shows duration, resolution, aspect ratio, frame rate, video and audio codecs, audio track count, container, size and source bitrate.
  4. Set the output. In video mode pick a preset, container, codec and resolution. In audio mode pick MP3, WAV, M4A or AAC, then the bitrate, sample rate, channels and audio track.
  5. Review the plan. The plan panel shows the exact output size, codecs and bitrates that will be requested before anything is encoded.
  6. Convert. The worker reports encoding and finalizing progress. Cancel at any time; the partial file is discarded and encoder resources are released.
  7. Verify and download. Preview the result, read the measured metadata, then download the file. Object URLs are cleaned up when you start another job.

Video to video: containers and codecs

A container is a box that holds video, audio and metadata. A codec is the method used to compress each stream. They are different decisions, and a container only accepts certain codecs. This tool offers the following combinations, and each one is filtered again by what the current browser can actually encode at the chosen resolution.

Container and codec combinations exposed by this tool
ContainerVideo codecsAudio codecTypical use
MP4H.264 (AVC), HEVC (H.265) when encodableAACBroad playback, phones, social platforms, editing apps
WebMVP9, VP8, AV1 when encodableOpusWeb pages, open formats, efficient streaming
MOVH.264, HEVC when encodableAACApple workflows and QuickTime-based editors
MKVH.264, HEVC, VP9, AV1 when encodableAACFlexible archival and desktop playback

HEVC is conditional. Most desktop Chrome builds cannot encode HEVC even though they can mux it, so the option is usually disabled. It is not removed from the list, because a browser or device that can encode it should be able to use it. AV1 encoding is likewise offered only where the browser reports support. VP8 is available as a widely supported WebM fallback when VP9 or AV1 is unavailable.

Input is more forgiving than output. A browser may decode H.264, VP8, VP9, AV1 and some HEVC files while being unable to encode all of them. The tool inspects the actual file and disables a conversion path when the decoder is missing. AVI is rejected because the engine used here has no AVI demuxer; remux or convert the AVI to MP4 or WebM first.

Video to audio: extracting MP3 and other formats

Audio extraction is its own job. The video stream is ignored, the chosen audio track is decoded, resampled to the selected sample rate, mapped to the selected channel count, and encoded with an audio encoder. The output is a real audio file with no video track, not a renamed video.

  • MP3 is the primary and most compatible choice. It is encoded with a bundled LAME-based encoder and written with a proper MP3 container and Xing header.
  • WAV stores uncompressed 16-bit PCM. It is lossless in the sense that it preserves the decoded samples, but it is much larger than MP3 and has no bitrate setting.
  • M4A stores AAC audio in an MP4 container. It is efficient and widely supported by Apple devices and players.
  • AAC writes a raw ADTS stream. Some players prefer M4A because it carries metadata and indexing more gracefully.

FLAC and other lossless codecs are not offered because this browser build has no usable FLAC encoder. Offering a format the tool cannot genuinely produce would be worse than omitting it.

If the video has several audio tracks, the track selector lists them with language, name, channel count, sample rate and codec where the file provides that information. The extract button stays disabled when there is no audio track or when the selected track cannot be decoded.

Choosing an MP3 bitrate

MP3 is a lossy format. The bitrate is the amount of data stored per second, so it directly controls the size and the amount of detail that survives. The size of a constant-bitrate MP3 is roughly the bitrate multiplied by the duration, divided by eight.

MP3 bitrate guidance for a one-minute clip
BitrateApprox. size per minuteBest for
320 kbps≈ 2.4 MBMusic where detail matters and storage is not tight
256 kbps≈ 1.9 MBHigh-quality music listening
192 kbps≈ 1.4 MBThe recommended default for music, podcasts and general use
128 kbps≈ 1.0 MBSpeech, voice notes and casual listening
96 kbps≈ 0.7 MBSpoken word where the smallest file matters most

A higher bitrate cannot restore detail that the source audio never contained. Extracting a 128 kbps AAC track from a video to a 320 kbps MP3 produces a larger file, not better sound. Match the target to the source and the purpose. Stereo roughly doubles the data compared with mono at the same bitrate, and 44.1 kHz is the natural choice for music, while 48 kHz matches most video audio.

Quality presets and advanced controls

High Quality allocates the most bits and can produce a file larger than the source. Balanced is the recommended default and aims to stay close to the source quality at a practical bitrate. Smaller File deliberately spends less data, which can soften fine texture and fast motion. The presets calculate a target from the output pixel count, the effective frame rate and the source bitrate, so the same preset behaves sensibly for a 4K clip and a 360p clip.

Advanced settings let you override the preset with an exact video bitrate, enable constant quality (CRF), and cap the frame rate. CRF asks the encoder for a consistent visual quality instead of a fixed bitrate; lower values keep more detail. Browser encoders differ, so a bitrate is always supplied as a fallback and the page says when the fallback is in use. A frame-rate cap drops extra frames and extends the previous frame, so duration and audio sync do not change and frames are never invented.

Resolution presets preserve the source aspect ratio. Custom dimensions can be locked to the source aspect or set freely; a different aspect is letterboxed inside the frame, never stretched. The page warns when an output is larger than the source, because upscaling adds pixels without adding real detail.

What the results mean

The result panel reads the finished file back and reports the real container, video codec, audio codec, resolution, duration, size and bitrate. For audio extraction it reports the codec, measured bitrate, sample rate, channel count and source track. A playable preview is shown when the browser can play the result.

Conversion is not compression. A Balanced conversion can be close to the source size, and High Quality can be larger. When the result grows, the page says so plainly instead of claiming a saving. Use the dedicated Video Compressor or the Smaller File preset when a smaller file is the goal.

Common reasons to convert a video

  • Device compatibility. A phone, tablet, TV or editor may prefer MP4 with H.264 and AAC over WebM or MKV.
  • Web delivery. WebM with VP9 or AV1 and Opus is efficient for modern browsers and HTML video.
  • Editing workflows. MOV and MP4 are widely accepted by desktop editors and Apple tools.
  • Archiving. MKV can hold a range of codecs in one flexible container.
  • Audio reuse. Extracting MP3 turns a recorded talk, lecture or music video into a portable audio file.
  • Podcasts and transcripts. A mono 96 or 128 kbps MP3 is small and easy to transcribe or publish.
  • Presentations and embeds. A smaller resolution reduces bandwidth without changing the clip's duration.

Privacy, performance and file limits

The page loads only its own stylesheet, the self-hosted Mediabunny engine, the MP3 encoder and the worker. The worker starts when it is needed and is terminated when you remove the video or leave the page. Source and result object URLs are revoked when you replace the file, start another job or navigate away. There is no upload, account, paid API or server-side copy.

Conversion speed depends on clip length, resolution, frame rate, the chosen codec and the device's encoder. 4K and long videos need more time and memory. The page warns when the input is large, the clip is long or the output is very large. Output is capped at 4096 pixels per edge and dimensions are rounded to even numbers, which the encoders require. Files above 2 GB are rejected before processing.

Troubleshooting

  • The file is rejected. The browser may not decode its codecs, the file may be corrupt, or it may be an AVI. Try an MP4 or WebM that plays in the same browser.
  • A container or codec is disabled. The browser cannot encode it at the chosen size or sample rate. Try another combination or a smaller resolution.
  • HEVC is greyed out. Most Chrome builds cannot encode HEVC. Choose H.264 for MP4 or MOV, or VP9 for WebM or MKV.
  • Audio extraction is disabled. The video may have no audio track, or the selected track may use a codec this browser cannot decode. Check the audio track list.
  • The MP3 is a little longer than the video. MP3 encoders add a small delay and padding. This is normal and does not mean the audio is out of sync.
  • The preview will not play. The browser may lack playback support even when the file is valid. Download it and open it in a media player.
  • It runs out of memory. Try a shorter clip, a smaller resolution or fewer channels, and close other heavy tabs.
  • The conversion is slow. Keep the tab open and avoid heavy background work. Long 4K clips are the slowest case.

Frequently asked questions

Does this video converter upload my file?

No. The file is decoded and re-encoded inside a Web Worker in your browser tab using Mediabunny and WebCodecs. It is not sent to LetitEdit or a third-party service, and no account is required.

Which video formats can I convert from and to?

MP4, M4V, MOV, WebM and MKV inputs are accepted when this browser can decode their video codec. Outputs are MP4, WebM, MOV and MKV, each limited to the video and audio codecs that can genuinely be muxed and encoded in this browser. AVI is not decoded by the browser engine and is rejected with an explanation.

Can I extract MP3 audio from a video?

Yes. Switch to Video to audio, choose MP3, pick a bitrate from 96 to 320 kbps, a sample rate and mono or stereo, then extract. The audio track is decoded and encoded with an MP3 encoder; the file is not renamed. WAV, M4A and AAC are offered when the browser can encode them.

Which MP3 bitrate should I choose?

192 kbps is a good default for music and general listening. 320 kbps keeps the most detail and creates the largest file. 128 kbps is fine for speech and casual listening, while 96 kbps saves the most space and may sound thin. MP3 is lossy at every bitrate, so a higher value cannot restore detail the source never had.

Will converting change the duration or audio sync?

The tool preserves frame timestamps and encodes audio against the same timeline, so audio stays aligned with the picture. If you cap the frame rate, extra frames are dropped and the previous frame is extended rather than duplicating frames. MP3 adds a small encoder delay and padding, so its duration can be a few milliseconds longer than the source.

Why is a container or codec disabled?

The tool asks the browser which codecs it can actually encode at the chosen resolution and sample rate. A container or codec that is unavailable is disabled with an explanation instead of producing a broken or mislabelled file.

What happens if the video has no audio track?

In Video to video mode the output is simply silent. In Video to audio mode the page says there is nothing to extract and keeps the extract button disabled. The tool never creates a silent MP3 or renames a video file as audio.

Does converting always make the file smaller?

No. Conversion is not compression. Balanced aims to stay close to the source quality, and High Quality may produce a larger file. The result panel reports the measured size and clearly states when the output grew. Use the Video Compressor or the Smaller File preset when size is the priority.

Can I convert more than one file at a time?

One file is converted per job so the preview, settings and result stay accurate. Remove the current file or start a new conversion to load another.

Is the conversion private?

Yes. The page loads only its own stylesheet, the self-hosted Mediabunny engine, the MP3 encoder and the worker. The file, the preview and the result stay in the browser tab, and object URLs are released when you replace the file, start another job or leave the page.
