Guide

How to edit an image in your browser

Open a file with the Import button or drag it onto the canvas. The editor reads the image locally, shows its dimensions and type, and keeps the original untouched until you export. Choose a tool on the left (desktop) or in the bottom bar (mobile), make the change, and use Undo if you change your mind.

  1. Open: choose JPG, PNG, WebP, GIF, BMP, SVG, TIFF, HEIC or AVIF. Support depends on the browser and the bundled decoders.
  2. Edit: crop, resize, rotate, adjust colour, apply a filter, add text, shapes or a drawing, or build the image from layers.
  3. Check: use Fit, zoom, pan and the Before button to compare the result with the original.
  4. Export: pick a format, quality and filename, check the real output size, then download.

Crop, resize and export the right dimensions

Crop changes what part of the image is kept. Resize changes the pixel dimensions of the cropped result. Frame adds padding, a background, rounded corners, a border or a shadow. The export panel shows the final dimensions after all three stages, so check it before downloading.

Use the ratio presets for common work: 1:1 for profile images and square posts, 4:5 and 9:16 for social stories, 16:9 for video thumbnails, and 3:2 or 4:3 for photography. The editor keeps the crop rectangle inside the image and lets you reset it at any time.

Compress and convert without guessing

JPG and WebP use a quality setting. Lower quality makes smaller files but can add visible artifacts. PNG is lossless and ignores the quality slider, so use it when transparency or exact pixels matter. BMP is available for compatibility but produces large files. AVIF export appears only when the browser exposes a working AVIF encoder.

The size estimate is approximate. If you set a target size, the editor tries several quality levels and reports the closest real result. It never promises an exact byte count that the encoder cannot guarantee.

Layers, text and shapes

Text, shapes, drawings and added images are separate layers. Move, resize, rotate, hide, lock, duplicate, rename or reorder them without flattening the original. The export is flattened only at the final step. Text uses the browser’s font shaping, including Unicode, Arabic and other RTL scripts; choose the direction in the Text panel when automatic detection is not enough.

Privacy: your image stays on your device

All editing and encoding happens in the browser with the Canvas API, Web Workers and local decoders. No image is uploaded to LetitEdit. The page does not require an account. If a future feature needs a server, it will be disclosed before the file leaves your device. No advertising code is placed over the editing canvas.

Common problems

A HEIC file will not open

The HEIC decoder is loaded on demand. Very large or unusual HEIC files may still fail. Export the image as JPG or PNG from your phone or camera app, then open that file here.

AVIF export is missing

Your browser does not expose an AVIF encoder. Choose WebP or JPG instead. The editor disables options it cannot genuinely produce.

The exported file is larger than expected

PNG and BMP are lossless. Use JPG or WebP, lower the quality, or reduce the dimensions. The export panel reports the actual size after encoding.

Transparent areas became white

JPG and BMP cannot store transparency. Use PNG or WebP to keep it.

Frequently asked questions

Does the editor upload my image?

No. Import, editing and export run in your browser with the Canvas API. Your image is not sent to LetitEdit or a third-party service.

Which formats can I open?

JPG, PNG, WebP, GIF, BMP and SVG are handled by the browser. AVIF depends on browser support. TIFF uses a bundled decoder. HEIC/HEIF uses a bundled decoder where the browser cannot open it natively.

Which formats can I export?

JPG, PNG, WebP and BMP are always available. AVIF export appears only when the browser provides a working AVIF encoder.

Can I keep transparency?

Yes, with PNG or WebP. JPG and BMP do not support transparency, so the editor fills transparent areas with white for those formats.

Can I guarantee an exact file size?

No. The editor can target a size for JPG and WebP and will report the real output size, but encoders cannot guarantee an exact byte count.

Does it correct EXIF rotation?

Yes. The browser applies the JPEG EXIF orientation while decoding, so photos taken in portrait open the right way up.

Does background removal use AI?

No segmentation model is bundled. Background removal is not advertised as working; the editor reports that limitation instead of showing a fake result.

Can I edit on a phone?

Yes. The mobile workspace uses a large preview, a bottom tool bar and bottom-sheet controls. The editor is tested from 320px wide and in landscape.
