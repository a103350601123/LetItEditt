In-depth guide

What the border tool does

A border tool solves a small but common problem: a photo needs a little space around it before it is posted, printed or placed on a slide. This one takes a single image and draws a solid colour frame around the outside of the original pixels. You set the width in pixels and choose one colour, and the preview shows exactly how the finished picture will look. Because the frame is added outside the image rather than painted over it, no part of your photo is covered or trimmed. The download is a new PNG file that contains both the original content and the frame. The file you uploaded stays untouched on your device, so you can try several colours or widths without losing the source. If you are preparing several versions, keep the original handy and export each variant separately.

A quick workflow

Upload one image to begin. The tool reads it locally and shows it in the preview area. Move the width control until the frame looks proportionate to the picture — a thick border can suit a small icon, while a large photo often needs only a slim edge. Next choose a solid colour. Neutral black or white is safe for most uses, but a colour sampled from the photo can look considered. Watch the preview as you adjust both settings, because the same width looks different on a small thumbnail and a large image. When the frame looks right, download the PNG. If you want to compare options, change the colour or width and download a second copy; each export is independent and the original file is never overwritten.

Choosing width and colour

Border width is measured in pixels, so its visual impact depends on the size of the image. On an 800-pixel-wide photo, a 20-pixel frame is a modest outline; on a 200-pixel avatar, the same setting dominates. Think about where the result will appear: a frame that looks balanced on a desktop preview may disappear in a social-media thumbnail. Colour matters just as much. A high-contrast frame separates the photo from a busy page, while a subtle tone lets the image speak for itself. Since the border is a single solid colour, avoid expecting gradients, patterns or separate colours per side. If you need those effects, a screenshot beautifier or a full design tool is a better fit.

Why the output is PNG

The tool exports PNG because it keeps the frame edges clean. A lossy format such as JPG would introduce faint blocking around the boundary between the solid colour and the photograph, which is exactly where a crisp edge matters most. PNG stores the pixels directly, so the colour stays even and the transition remains sharp. The trade-off is file size: a bordered PNG can be larger than a comparable JPG, especially for a photo with lots of detail. If size matters more than edge quality, you can run the downloaded file through an image compressor afterwards. Remember that adding a border increases the canvas dimensions by twice the border width in each direction, so a 50-pixel frame adds 100 pixels to both the width and the height.

Privacy and troubleshooting

All drawing happens in your browser, and the image is not uploaded anywhere. That makes the tool convenient for pictures you would rather not send to a remote service. If the border seems too thin, increase the width and check the preview again; a handful of pixels can be nearly invisible on a high-resolution display. If the frame appears to blend into the page, pick a colour with stronger contrast against what surrounds the picture. A frame that looks uneven is usually an optical effect caused by a very wide border on a small image, so try reducing it. Very large photos can take a moment to render; wait for the preview to settle before downloading, and reload the page if it stops responding. You can also try a different source format if one particular file never renders correctly.

Frequently asked questions

Does the image leave my device?

No. The border is drawn in your browser with canvas, and the file is never uploaded to LetitEdit or another service. Your original image is not modified.

Can I use different colours on each side?

No. This tool adds a single solid colour border of equal width on all four sides. For multiple colours or uneven frames you need a full graphic editor.

What happens at the image edges?

The border is added outside the original pixels, so nothing is cropped or covered. The downloaded PNG is wider and taller than the input by twice the border width.

Why is my downloaded file a PNG?

PNG keeps the solid colour edges crisp and avoids compression smudging around the frame, so it is the export format for this tool.

The border looks thin or invisible. What should I check?

Increase the width value; a few pixels can be hard to see on a large preview. Also check that the chosen colour contrasts with the image edge, because a white frame on a white background is easy to miss.
