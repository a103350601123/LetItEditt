In-depth guide

What the converter does

A black and white conversion removes color information and keeps the brightness of each pixel. This tool does that work in your browser, so a photo, logo or scan never has to leave your device. Two modes cover the usual jobs: a smooth grayscale render for photographs and an adjustable threshold for artwork that should contain only pure black and white. You open an image, pick a mode, check the preview and download the result. Nothing is renamed or reordered, and no account is needed. Because the image is processed as pixels, the output keeps the same dimensions as the source unless you resize it elsewhere. The original file on disk is never changed, so you can compare versions side by side.

Grayscale mode for photographs

Grayscale mode blends the red, green and blue channels into a single luminance value, producing a continuous range of gray tones. Skin, fabric, sky and shadows remain distinguishable because hundreds of shades are preserved. This is the right choice for portraits, landscapes and any picture where texture matters more than a stark graphic effect. The converter uses a weighted luminance calculation, so colors with the same brightness do not necessarily look identical afterward; a saturated red can become darker than a pale blue. If a photo looks flat in grayscale, try increasing contrast in an image editor first, then bring it back here for the final black and white pass. That weighting matches human perception better than a simple average.

Threshold mode for line art

Threshold mode reduces every pixel to one of two values. A slider sets the cut-off: pixels darker than it become black, and lighter pixels become white. That simplification is useful for scanned signatures, pencil sketches, stamps, diagrams and text that will be printed at small sizes. Adjust the slider while watching the preview, because a cut-off that is too high thickens lines and fills fine gaps, while one that is too low drops faint strokes. Threshold is not a substitute for a scanner's descreening; moire patterns from printed halftones can survive. For a high-contrast line art effect, start with a clean, evenly lit scan and then fine-tune the slider. Test the slider on a small crop before processing a whole page.

Transparency and export formats

Transparency is preserved in both modes. The alpha channel is left alone, so a cut-out on a transparent background keeps its soft edges and a product photo does not gain a white rectangle. To keep that transparency, download PNG or WebP. JPG stores no alpha information, so any transparent area is flattened, usually to white or black. PNG is the safest choice for logos and overlays; WebP gives smaller files for web use; JPG is fine when the background is already solid. Re-encoding always writes new pixels, so export once from the version you are happy with instead of repeatedly downloading and reopening the same file. Keep a lossless master copy if you plan several exports.

A quick conversion workflow

Start by opening a PNG, JPG or WebP file from your device. Choose Grayscale for a photograph or Threshold for artwork that needs crisp edges. In threshold mode, move the slider in small steps and watch thin lines and empty spaces; stop when the drawing reads cleanly at the size you plan to use it. Zoom the preview to catch broken strokes before downloading. If the image has a transparent background, confirm it still looks transparent in the preview, then pick a format that supports alpha. Download the file, give it a clear name and compare it with the original. If the result is too heavy or too large for a web page, resize or compress it afterwards.

Limits and troubleshooting

This tool changes tone, not content. It cannot colorise an old photograph, repair scratches, straighten a skewed page or add missing detail to a low-resolution scan. Very large images need more memory and may take a few seconds to update, especially in threshold mode where every pixel is examined again. If the preview appears blank or unchanged, check that the file actually opened and that a supported format was used. Noisy results usually come from JPEG compression or uneven lighting; a cleaner source gives a cleaner cut-off. All processing is local, but remember that clipboard screenshots, shared screens and downloaded files can still expose an image you intended to keep private. If a file will not open, try re-saving it from the source application.

Frequently asked questions

Is my image uploaded anywhere?

No. The conversion runs in your browser using the image data you open. Nothing is sent to a server, and closing the page clears the working copy.

What is the difference between grayscale and threshold?

Grayscale maps each pixel to a shade of gray, keeping subtle detail. Threshold converts pixels to pure black or white based on a slider, which suits line art, stamps and text scans.

Will transparent pixels stay transparent?

Yes. Alpha values are left unchanged in both modes, so logos and cut-outs keep their soft edges. Choose PNG or WebP to preserve transparency; JPG does not support it.

Can it colorise or restore an old photograph?

No. It only removes color information. It cannot add color, repair scratches, straighten a skewed page or enlarge a small image.

Why does my threshold preview look too dark or too noisy?

Lighting and compression artifacts push pixels across the cut-off. Move the slider slowly, try grayscale first, and use a clean evenly lit scan for crisp line art. Large images may take a moment to render.
