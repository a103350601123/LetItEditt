# LetitEdit Video Editor

A private, browser-based video editor. It runs entirely in the browser: multi-track timeline, animated titles, canvas effects, captions, voiceover, and real-time canvas export. No account, no uploads, no bundled third-party media, and no watermark.

This is the standalone editor under `tools/video-editor/`. It is plain HTML/CSS/JS with no build step.

## Run it

From this folder, use any static server:

```powershell
node serve.js
# open http://localhost:4173/tools/video-editor/
```

Or:

```powershell
python -m http.server 4173
# open http://localhost:4173/tools/video-editor/
```

Opening `index.html` directly from disk mostly works, but `http://localhost` is recommended so IndexedDB, media decoding, and fullscreen behave consistently.

## What works

- **Multi-track timeline** — video, overlay, text, and audio tracks with a documented cap of **24 tracks** per project. Drag to move, drag edges to trim, split, duplicate, delete, snapping, and zoom.
- **Layer and track control** — reorder layers across tracks (`[` / `]`, inspector buttons, or on-canvas handles), lock/hide individual layers, reorder tracks with ↑/↓, lock/mute/hide tracks, and group a track with its adjacent neighbour. Grouped tracks share lock/mute/hide state and move together.
- **On-canvas editing** — click a clip at the playhead to select it, drag its body to reposition, drag a corner to resize, and drag the yellow handle to rotate. Locks are respected.
- **Canvas and layout** — 16:9, 9:16, 1:1, 4:5, 4:3, and 21:9; background colour; position, scale, rotation, and opacity. The layout switches to drawers on narrow screens (320–768 px), so both the library and inspector remain reachable rather than being hidden.
- **Text and animation** — 14 text styles, 14 ready-made text presets, **53 system/generic font stacks**, and **56 animation presets** (55 animated/transition presets plus “No animation”). Presets cover entrances, exits, loops, typewriter effects, wipes, glitches, motion loops, and highlight effects. Duration, speed, delay, and direction are editable.
- **Real effects** — 24 renderable effects plus Off: grades, film grain, glitch, VHS, blur, sharpen, vignette, light leak, scanlines, chromatic aberration, duotone, glow/halation, pixelate, and more. Effects are applied in the canvas compositor and are therefore present in both the preview and exported video. Pixel-level effects cost more CPU at high resolutions.
- **Look and transitions** — 14 colour filters plus eight in/out transition types (fade, slides, zoom, wipe, blur).
- **Library** — 10 categories: All, Video, Audio, Image, Sticker, Sound FX, Shape, Animated, Text, and Decorative. Imported files come only from your device. **22 procedural graphics** are generated by the canvas renderer; there are no bundled stock assets or fake asset buttons.
- **Captions and audio** — add captions manually, import `.srt`/`.vtt`, export text clips as `.srt`, per-clip volume/fades, and microphone voiceover recording where the browser supports `MediaRecorder`.
- **Projects** — autosave to IndexedDB, plus portable `*.letitedit.json` files containing edit data and asset metadata. Missing media can be relinked.
- **Undo/redo** — snapshot history for edits, track changes, and project settings.
- **Export** — composites the same canvas renderer and records via `MediaRecorder`. MP4/H.264 where supported, otherwise WebM; 480p–2160p, 24/30/60 fps, and quality control.

## Migration from earlier builds

Older projects still open. On startup:

- The IndexedDB database `clipforge` is migrated once into `letitedit`.
- The `clipforge:prefs` preference key is migrated once into `letitedit:prefs`.
- Project payloads are normalised by `VE.sanitizeProject()`: version becomes `2`, `app` becomes `LetitEdit Video Editor`, legacy clips gain effects/animation/lock/hide defaults, and invalid values are clamped.

New project files use the `.letitedit.json` extension. The literal legacy identifiers remain in `js/db.js` and `js/app.js` only for migration; they are not visible branding or stored project names.

## Privacy, storage, and licensing

- Everything runs locally. Nothing is uploaded.
- Media blobs, thumbnails, and the current project are stored in IndexedDB (`letitedit`) in this browser profile. “Clear browser storage” permanently deletes them.
- Project files contain the edit plus asset metadata, **not** the media bytes. Moving an edit to another device requires relinking the original files.
- **No external font CDN, stock library, or copied media is used.** Font options are CSS stacks of fonts shipped with common operating systems or generic families (`system-ui`, `serif`, `monospace`, etc.). Built-in graphics and the demo are generated/drawn in code. Imported media remains solely the user's own file and its existing licence.
- The editor links to no external services and makes no telemetry requests.

## Honest limitations

- Automatic speech-to-text is not bundled. Import an SRT/VTT from your transcription tool or type captions manually.
- There is no bundled music, sticker, or stock-video library; you import your own files.
- Export is **real-time**, not offline/faster-than-real-time. Keep the tab visible and focused while exporting.
- MP4 output depends on browser codec support; Firefox/Safari commonly produce WebM instead. Long 4K/60 timelines can exceed device encoding capability.
- Media support depends on the browser's codecs. MOV/MKV may not play everywhere; MP4/WebM is safest.
- Track groups are adjacent pairs created with the group button. Non-adjacent grouping is not supported.
- Layer Z-order is shared across all tracks; the lowest timeline row renders in front.
- The 24-track cap is enforced to keep live media decoding predictable; actual performance still depends on the device and media resolution.
- On-canvas resize uses uniform scale for media/text and width/height for procedural shapes; it is an editing convenience, not a free-transform tool.

## Checks

Focused checks live in `tests/selftest.js` and can be run with:

```powershell
node tests/selftest.js
```

They verify branding constants, catalog counts, project sanitisation/migration, layer ordering, animation evaluator distinctness, and procedural clip creation without needing a browser.
