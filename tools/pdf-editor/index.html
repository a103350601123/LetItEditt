Free PDF Editor — Edit, Annotate and Fill PDFs in Your Browser

Toolbox PDF Editor lets you add text, highlights, freehand drawings, whiteouts, images and signatures to any PDF, then download a clean, flattened copy. There is no sign-up, no watermark, no page limit and no upload — the entire editing session happens inside your own browser. It works with a mouse, stylus or finger on a desktop, tablet or phone, and it is completely free.

What is a PDF Editor?

A PDF editor is a tool that lets you change a PDF document without rebuilding it from scratch. The PDF format was designed to look identical on every device, which makes it excellent for sharing invoices, contracts, forms, worksheets and reports — but it also makes a PDF hard to change with ordinary word-processing software. A dedicated PDF editor opens the document, draws new content on top of the existing pages, and saves the result as a new PDF.

Most people do not need to rewrite a PDF from the ground up. They need to correct a typo, sign a lease, tick boxes on a form, comment on a draft, highlight a clause, hide an account number, or add a note to a scanned letter. That kind of everyday work is exactly what this editor is built for. You can click existing text to edit it in place, place a new text box anywhere on a page, drag a highlighter over printed text, sketch with a pen, cover a line with a whiteout rectangle, or drop a photo of your signature onto the page. When you are finished, the changes are flattened into the document so the file opens and prints correctly in Adobe Acrobat, Chrome, Edge, Safari, Preview and on mobile PDF readers.

How to use this free PDF editor

  1. Open your PDF. Click “Open PDF” in the top bar, press the drop zone, or drag a file onto the page. The document is rendered locally with a PDF engine in your browser.
  2. Pick a tool from the floating toolbar. Select, Text, Edit text, Sign, Highlight, Draw, Whiteout, Redact, Image, Erase and More tools sit directly above the page. The active tool is highlighted, and its options — font, colour, brush size or text snapping — appear in the bar underneath.
  3. Edit or mark up the page. Choose Edit text and click an existing line to replace it, or tap the page with Text to add a new box. Open the signature pad to draw or upload a signature. Drag across a sentence to highlight it, sketch with the pen, cover content with Whiteout, or drag a Redact box over information that must be removed from the file itself.
  4. Use More tools for whole-document jobs. Add page numbers and watermarks, read text in a scan with local OCR, compress the file, split it into a ZIP of smaller PDFs, add other PDF files, insert a blank page, turn every page right, reverse the order, or save the current page as a picture.
  5. Adjust and organise. In Select mode you can drag text boxes and images, edit text, resize an image from its corner handle, and delete anything you do not want. Undo and Redo cover every mark, and the page button at the bottom opens thumbnails for quick navigation.
  6. Download the edited PDF. Press “Save PDF”. The annotations are drawn into a copy of the original file, redacted pages are replaced with flat images, and the finished document is saved straight to your device.

What can you add to a PDF?

  • Click-to-edit text that is already in the PDF. The editor preserves the line's position, bold weight, colour and background, supports multilingual text, and flattens the replacement with a matching cover layer.
  • Whiteout rectangles that cover text, numbers or a whole area with solid white in the preview and the export.
  • True redactions that replace an entire affected page with a flat image on export, so the covered words are not left in the PDF's text layer. Cover the full line or area before you share the file.
  • Text boxes in Helvetica, Times New Roman or Courier, with adjustable font size and any colour. Text wraps automatically, and you can drag a box anywhere on the page.
  • Highlights that can snap to real text lines, so a drag across a paragraph produces tidy, evenly aligned marker strokes instead of a lopsided rectangle.
  • Freehand drawings for signatures, initials, arrows, circles, margin notes and quick diagrams, with a brush from 1 to 24 points and a full colour picker.
  • Images and signatures in PNG, JPG, GIF, WebP or SVG. Draw a signature with a mouse, stylus or finger in the signature pad, or upload an image. Signatures are added to the page and can be dragged and resized while keeping their proportions.
  • Page numbers, watermarks and searchable text from the More tools panel, including local OCR that reads printed text from scanned pages and can place it invisibly into the PDF.
  • Document operations such as compression, page splitting, merging extra PDFs, inserting blank pages, rotating all pages, reversing page order and exporting a page as a PNG picture.
  • An eraser for removing a single annotation without clearing the page, plus a “Clear this page” action and a deep undo history.

Why our PDF editor is safe

Privacy is the main reason this tool exists. When you use a typical online PDF editor, your document is uploaded to a remote server, processed there, stored for an unknown amount of time, and downloaded again. That is a serious problem when the file is a contract, a medical letter, a bank statement, a passport scan or a signed agreement.

This editor does the opposite. The PDF is opened with JavaScript on your own device, the pages are painted onto HTML canvases in your browser, and the annotations are written back with a local PDF library. No file, page, thumbnail or annotation is ever transmitted. There is no account to create, no email to confirm and no document history on a server, because there is no server involved in the editing process. The page loads open-source PDF, ZIP, OCR and font libraries from public CDNs; OCR recognition and every other operation then run locally in your browser. Once the page is loaded, you can switch off your internet connection and keep working.

When you close the tab, the document is gone from memory. Nothing is left behind except the file you chose to download.

Free forever, with no watermarks or page limits

Every feature on this page is available to everyone. There is no premium tier, no credit system, no “export to remove the watermark” upsell and no limit on how many pages you can annotate. You can edit a one-page form or a two-hundred-page report, export as many copies as you need, and use the tool on any device with a modern browser. No payment details are requested at any point.

Designed for phones, tablets and touch screens

Most PDF editors treat mobile as an afterthought: tiny buttons, hover-only menus and canvases that scroll while you try to draw. This one was rebuilt around the Pointer Events API, which means the same code responds to a mouse, a stylus and a finger. The toolbar buttons are at least 44 by 44 pixels, the page always fits the screen width with no sideways scrolling, and touching the page with the highlight, pen or whiteout tool pauses page scrolling until you lift your finger. Text boxes open the on-screen keyboard when you tap the page, and images can be dragged and resized with a fingertip.

Tips for a clean, professional result

  • Use the highlighter’s text-snapping option for documents with selectable text; it produces much neater results than a freehand rectangle.
  • For a true redaction, choose the Redact tool and cover the whole line or area. Affected pages are rasterised on export, so the hidden text is removed rather than merely covered. Whiteout is only a visual cover.
  • For a signature, use the Sign pad to draw with a finger, stylus or mouse, or upload a clean image of your handwriting. The editor crops and places it for you — drag the corner handle to fine-tune.
  • Keep annotation text in the same font family as the document where possible. Helvetica and Times New Roman match the majority of business PDFs.
  • Download a copy before making major changes if you want to keep an untouched original. The export always creates a new file and never modifies your source document.

Frequently Asked Questions (FAQs)

Is this PDF editor really free?

Yes. Every tool, colour, font and export is free, with no watermark, no page cap and no account. There is nothing to unlock and no trial period.

Are my PDF files uploaded to a server?

No. The PDF is read and rendered by your browser, and the edited file is generated on your device. No document data is sent anywhere. The page only loads the open-source PDF libraries and a web font from public CDNs.

How do Whiteout and Redact differ?

Whiteout draws a solid white box in the preview and in the export. It is a visual cover. The Redact tool also replaces the whole affected page with a flat image when you export, so the covered words are no longer present in the PDF’s text layer. Cover the entire line or area with Redact before you share a file.

Can I edit the existing text inside a PDF?

Yes. Choose the Edit text tool and click directly on a line of real PDF text. The editor detects the line's font family, bold weight, size, colour, background and position, then keeps the replacement on the same spot without reflowing the page. Multilingual text is supported with embedded free Noto fonts; scripts that need special shaping, such as Arabic or Devanagari, are exported as sharp transparent text images so they still look right. Text that is only pixels in a scanned image cannot be detected; use Whiteout and a new text box for those documents.

Does it work on a phone or tablet?

Yes. The layout stacks neatly on small screens, the toolbar buttons are enlarged for touch, and the page always scales to fit the screen width, so there is no sideways scrolling. Drawing, highlighting, whiteouts, text and image placement all work with a finger or a stylus. While a pen or highlighter stroke is in progress, page scrolling is paused so the canvas does not move under your finger.

Can I sign a PDF with my signature?

Yes. Open the Sign pad to draw your signature with a mouse, stylus or finger, choose the ink colour and pen size, or upload an image of your handwriting. The editor crops the result, places it on the page and lets you drag and resize it before export.

Can I add page numbers and watermarks?

Yes. Open More tools and choose where numbering starts and where it sits on the page, then press “Add page numbers”. The watermark panel lets you set the text, opacity, angle, size and colour. Current marks are flattened first, and the updated file is reloaded so you can keep editing.

Can this editor read text in a scanned PDF?

Yes. More tools includes an OCR action powered by Tesseract.js. It runs locally in your browser and works best on clear, printed text. You can copy the recognised text or add it back to the PDF as invisible, searchable text. Recognition is not perfect, so always proofread the result. The language data and OCR library are downloaded from a public CDN the first time you use them.

Can I compress, split, merge or reorder PDF pages?

Yes. Compression rasterises pages to JPEG at your chosen quality, which usually makes scanned files much smaller but makes text non-selectable. Split can save separate PDFs into one ZIP using a page count like “2” or ranges like “1-3,4-6”. Add PDF files appends other documents, and the panel can also insert a blank page, turn every page right, reverse the page order and save the current page as a PNG picture.

Will the exported PDF still be editable?

The original pages are kept intact. Your annotations are flattened onto the pages, which is what makes the file display correctly in every PDF reader. You can always reopen the exported PDF here and add more marks.

Is there a file size or page limit?

There is no imposed limit. Very large documents depend on your device’s memory, so on an older phone it is best to work one section at a time. Pages are rendered as you scroll, which keeps memory use reasonable.

Which browsers are supported?

Current versions of Chrome, Edge, Firefox, Safari, Opera and Samsung Internet on desktop, Android and iOS. Pointer Events and JavaScript must be enabled, which is the default in all modern browsers.
