How to use Text to List Converter

  1. Paste or type the text to split.
  2. Choose Split by Line, Comma or Custom and enter a separator if needed.
  3. Choose a bullet, numbered, dash or custom-prefix format.
  4. Click Convert to List, then Copy or Clear.

In-depth guide

Splitting and formatting

The input is trimmed once before splitting. Line mode splits on line feeds and drops blank lines, comma mode splits and trims each part, and custom mode uses the separator you provide. A custom separator cannot be empty.

Formatting is applied in order: bullets use a bullet character, numbered items use 1-based numbers, dashes use a hyphen, and custom prefixes are followed by a space.

Frequently asked questions

What is the default separator?

Lines. The reference documentation mentions a comma default, but the application code selects “Split by Lines” by default.

Are items trimmed?

Comma and custom-separator items are trimmed. Line-mode items are filtered when empty but keep their original leading and trailing whitespace.

Is there a Number Range dropdown?

No. The reference text mentions one, but the tool uses radio buttons for split and format instead.
