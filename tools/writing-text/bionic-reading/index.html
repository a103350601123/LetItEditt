How to use Bionic Reading Converter

  1. Paste text or load the built-in sample.
  2. Set fixation strength, saccade skipping, fade, font, size, line height and theme.
  3. Use the preview to judge the pattern, then open Reading view for continuous reading.
  4. Copy formatted text, HTML or Markdown, or download a standalone HTML file.

In-depth guide

Unicode-aware word handling

Words are matched with Unicode letter, mark and number properties, with internal straight or curly apostrophes allowed. Numbers, URLs, email addresses and bare domains are left unbolded so links remain readable.

Fixation points are chosen by grapheme, so accented characters and many Indic conjuncts are not split awkwardly. The interface uses real bold elements in the preview and escapes all text before producing HTML or Markdown.

Local persistence

Text and options are saved to local storage after a short delay. This is convenient, but it means the text remains on this device until you clear it. The downloaded HTML file contains only your own output and no third-party branding.

Frequently asked questions

Does it handle apostrophes and hyphens?

Apostrophes inside words are handled. Hyphens are not part of the word pattern in the reference source, so “well-known” is treated as two words and may be bolded unevenly when saccade skipping is on.

Is my text uploaded?

No. Processing is local. This build saves your text and settings in this browser’s local storage so the preview survives a refresh; clear the text to remove it from the saved state.

What do fixation and saccade mean?

Fixation strength controls how much of each selected word is bold, from about 20% to about 70%. Saccade controls how often a word is selected: every word, every second word or every third word.
