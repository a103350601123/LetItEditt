Frequently asked questions

How do you count words?

We use the browser's Intl.Segmenter word segmentation when available. It understands languages that do not use spaces. Older browsers fall back to Unicode letter and number groups.

Are emoji counted as one character?

Yes. We count user-perceived grapheme clusters, so an emoji is one character rather than two UTF-16 code units.

What reading speed is assumed?

Reading time uses 200 words per minute and rounds up to at least one minute for non-empty text.
