Text Splitter

Create predictable chunks with a visible --- separator between parts.

Interactive tool

Runs in your browser

Output

How to use Text Splitter

  1. Paste text.
  2. Choose the unit and number of parts or chunk size.
  3. Copy each chunk as needed.

Example

Input
one two three four
Output
one two --- three four

Frequently asked questions

Does it split words in half?

No. Word and line modes keep whole units. Character mode respects grapheme clusters.
