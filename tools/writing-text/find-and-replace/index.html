How to use Find and Replace

  1. Enter the text or pattern to find and its replacement.
  2. Leave Case-sensitive on for a literal, case-sensitive replacement of every occurrence.
  3. Turn it off to compile Find as a regular expression with the g and i flags.
  4. Paste source text, click Replace all and copy the result.

In-depth guide

Two different matching engines

The case-sensitive branch uses literal string replacement, so every character in Find is matched exactly. The other branch passes Find directly to the regular-expression engine with global and case-insensitive flags.

That difference is intentional because it matches the supplied source. An invalid regular expression is caught and reported instead of throwing an uncaught browser error.

Advertised but not implemented

The reference page mentions whole-word searching and Word or HTML export. Neither exists in its application code. This implementation does not add them silently; the FAQ above records the gap so you can choose another tool when you need those features.

Frequently asked questions

Is whole-word search supported?

Not as a separate control. The reference tool advertises whole-word search but does not implement it. In regex mode you can add word boundaries such as \b yourself.

Can I export the result to Word or HTML?

No. Export to Word or HTML is advertised in the reference description but is not implemented there either. This tool provides a result box and a copy button.

Why did my search match more than expected?

With case sensitivity off, Find is compiled as a regular expression. Characters such as . * + and ( ) are active pattern syntax. A literal mode is used when the checkbox is on.
