Add Prefix or Suffix

Apply a prefix, suffix or both to each non-empty line while preserving line order.

Interactive tool

Runs in your browser

Output

How to use Add Prefix or Suffix

  1. Paste a list.
  2. Enter prefix and/or suffix.
  3. Copy the formatted lines.

Example

Input
apple banana
Output
- apple - banana

Frequently asked questions

Can blank lines be skipped?

Yes. Enable Skip empty lines to leave blank lines unchanged.
