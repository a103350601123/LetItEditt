In-depth guide

Why some artifacts remain

The reference filter matches ranges of Unicode code points rather than whole emoji grapheme clusters. A family emoji or a keycap number is built from several code points; removing the pictographs can leave a zero-width joiner or a combining mark behind.

This build keeps that behaviour for fidelity. Always review the output if the text will be published or shared.

Frequently asked questions

Does it remove every emoji?

No. The filter uses a broad range list, but joined emoji sequences and keycap marks can leave behind zero-width joiners or combining characters. Some non-emoji symbols in the same ranges are also removed.

Does a selected file override pasted text?

Yes. That matches the reference workflow: if a file is selected, its contents are processed instead of the pasted text.

Does it change spaces?

No. Only matched code-point runs are removed. Whitespace and formatting are preserved.
