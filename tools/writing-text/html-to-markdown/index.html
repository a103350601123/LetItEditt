Rich Text / HTML to Markdown

Paste markup from a webpage or rich-text editor. Common inline and block formatting is converted to standard Markdown.

Interactive tool

Runs in your browser

Output

How to use Rich Text / HTML to Markdown

  1. Paste HTML into the input box.
  2. Markdown is generated automatically.
  3. Copy the Markdown output.

Example

Input
<h2>Hello</h2><p><strong>World</strong></p>
Output
## Hello **World**

Frequently asked questions

Which elements are supported?

Headings, paragraphs, links, bold, italic, inline code, lists, blockquotes, line breaks and preformatted blocks.

Do I need to upload a .docx file?

No. This version accepts pasted HTML or rich text. Complex Word files should be saved as HTML first.
