How to use Rich Text / HTML to Markdown

      
  1. Paste HTML or rich text, or load an HTML, TXT, CSV, Markdown or DOCX file.

      In-depth guide
      
What the converter preserves

      
The converter reads the markup as text and walks it locally. Headings keep their level, links keep their destination and title, and emphasis becomes asterisks or underscores. Lists are nested with indentation, blockquotes get a leading marker, code blocks are fenced, and simple tables are emitted as pipe tables. Images keep their source and alt text.

      
Whitespace is normalised between inline elements so pasted rich text does not produce broken sentences. Entities such as ampersands and non-breaking spaces are decoded before the Markdown is written.

      
Safety and honest limits

      
Nothing is uploaded and no remote service is called. Script, style, SVG, iframe, object and form elements are dropped, as are event-handler and javascript: attributes. The side-by-side preview is assembled from DOM nodes using a strict allow-list, so markup in your own input cannot run code or alter the page.

      
This is a pragmatic converter for common web markup, not a full HTML5-to-CommonMark implementation. Complex nested tables, definition lists and custom elements may be simplified. DOCX files are read as ZIP archives where the browser supports decompression; only paragraph text is extracted, so layout and styling are lost.

  





  

    

      
Frequently asked questions

      

  Which elements are supported?
  
Headings, paragraphs, links, bold, italic, inline code, fenced code, ordered and unordered lists, nested lists, blockquotes, tables, horizontal rules, line breaks and images.



  Is pasted script or styling executed?
  
No. Scripts, styles, SVG, iframes and unsafe attributes are discarded. The preview is built with text nodes and a small allow-list of safe elements, never with innerHTML containing your content.



  Can I convert a Word document?
  
You can load a DOCX, but only its text is extracted. Tables, columns and styling are not kept. For a fully faithful layout conversion, export the document as HTML first.
