How to use Text Cleaner

  1. Paste the text you want to clean, or type directly into the input box.
  2. Choose options under Whitespace, Characters, HTML, Other text and Text formatting.
  3. Use All, None or Default to set many options at once.
  4. Click Clean Text. The result appears on the right; use Undo to step back.

In-depth guide

A fixed processing order

Text Cleaner applies rules in a defined sequence: whitespace first, then character filters, HTML and decoding, links, and finally formatting. This matters because rules can interact. For example, stripping HTML tags before removing extra spaces produces different output from doing it the other way around.

The order in this build follows the supplied reference application so that results are predictable for people moving between the two tools.

Honest limitations

HTML rules use regular expressions rather than a real HTML parser. Tag stripping removes anything between angle brackets, and attribute removal only matches quoted values. The “Strip emoji” option covers a small set of Unicode blocks and also treats literal pipe characters as literal characters, matching the reference implementation.

If you need precise HTML sanitisation or complete emoji removal, use a dedicated tool instead. This page reproduce the reference behaviour, including its quirks.

Frequently asked questions

Does this upload my text?

No. Cleaning happens entirely in your browser. Nothing is sent to a server.

Does Strip emoji remove every emoji?

No. It targets the common pictograph ranges used by the reference tool, so some modern emoji, flags and joined sequences can remain. Use the Remove Emojis tool for the broader Unicode-range filter.

What does the Default preset select?

It selects trim, remove leading and trailing spaces, strip HTML tags, strip emoji, collapse multiple spaces and reduce multiple blank lines. It leaves letter case unchanged.

Can I undo a cleanup?

Yes. The Undo button restores the previous result. It is a simple history for this tool, not a full text-editor undo stack.
