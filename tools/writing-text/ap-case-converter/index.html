In-depth guide

Six ordered rules

The converter title-cases ASCII words, lowercases a fixed list of short words, capitalises the first character after a period, shortens month names, shortens US state names and finally turns single digits into words. Each rule has its own checkbox.

State abbreviations are applied longest-first so multi-word states such as New York are matched before shorter names.

Know the limits

This is a formatting aid, not an authoritative style guide. The numeral rule converts any single digit, including day numbers in dates, so “May 5” becomes “May five”. Always review the output before publication.

Frequently asked questions

Is this a complete AP style checker?

No. It is a shallow regex pipeline covering title case, short words, sentence starts, month and state abbreviations and single-digit numerals. It does not handle titles, dates, times, currencies or Washington, D.C.

Why does Lowercase short words stop working when title case is off?

In the reference source that rule is nested inside the title-case rule. This build preserves the behaviour. Turn title case on if you need short words lowercased.

Does sentence capitalisation understand question marks?

No. The reference rule only looks for a period followed by whitespace, so question marks, exclamation marks and newlines do not start a new sentence.
