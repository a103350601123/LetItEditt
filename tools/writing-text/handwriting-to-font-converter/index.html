In-depth guide

What this scoped tool does

The pad stores one drawing per character. The preview takes each drawn glyph, scales it to the chosen size and tiles the glyphs into a sample image. Undo and clear apply to the selected character only.

A PNG download is genuinely useful for mock-ups and for checking how a set of letters looks together, but it is not a font that an operating system can install.

What the reference tool does

The supplied reference application includes a canvas editor, printable corner-marker templates, photo import with perspective correction, ink thresholding, contour tracing, per-character spacing controls and an embedded OpenType writer. Reproducing that stack faithfully would require a large, separately audited font pipeline.

This page keeps its own URL and states the difference plainly rather than implying that a font file is produced. For handwritten pages, use the preserved Text to Handwriting tool linked from the workspace.

Frequently asked questions

Can I download a .otf font?

No. Producing an installable OpenType font needs a contour tracer and CFF/OTF writer and is outside this build. This tool exports a PNG picture of your glyphs instead.

Is this the same as Text to Handwriting?

No. Text to Handwriting places typed text on notebook paper and exports PNG or PDF pages. This tool focuses on drawing individual letter shapes and previewing them as a sample.

Is my handwriting uploaded?

No. Drawing, preview and export all happen in your browser.
