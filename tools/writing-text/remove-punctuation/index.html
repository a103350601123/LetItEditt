      In-depth guide
      
Three ways to choose what gets removed

      
The default All mode looks at the Unicode punctuation property, so it handles straight and curly quotes, em and en dashes, ellipses, and punctuation from scripts beyond Latin. Common mode uses a shorter list of marks that are familiar in English prose, which is useful when you want dashes or apostrophes left alone. Custom mode removes exactly the characters you type into the box and nothing else.

      
Whitespace is never treated as punctuation. Spaces, tabs and line breaks stay where they are, so the shape of your paragraphs and lists survives the operation. That makes the output safe to paste into a spreadsheet or a plain-text editor.

      
Documents and honest scope

      
Text-like files such as TXT, CSV, TSV, Markdown, JSON and HTML are read directly as text. DOCX files are opened as ZIP archives in the browser and the paragraph text is extracted from the document XML. If the browser cannot decompress the archive, the tool reports the problem and suggests saving the document as text instead.

      
Only text is processed. A DOCX file can contain tables, columns, text boxes, headers and character formatting; none of that layout is preserved. PDF files and legacy .doc files need parsers this browser tool does not include, so they are rejected clearly rather than guessed at.

  





  

    

      
Frequently asked questions

      

  Are emoji and non-Latin scripts kept?
  
Yes. Only punctuation characters are removed. Letters from every script, numbers, emoji, symbols, spaces and line breaks are kept.



  What is the difference between all and common punctuation?
  
All uses the Unicode punctuation property and also removes marks such as curly quotes, em dashes and CJK punctuation. Common removes only the familiar English marks: . , ! ? ; : ' " ( ) [ ] { } - – — _ / \ @ # & * and the quotation variants.



  Can I open a Word document?
  
DOCX files are read locally where the browser supports decompression and only their text is cleaned. Layout, tables and styling are not kept. PDF and legacy .doc files are rejected with an explanation instead of being silently mangled.
