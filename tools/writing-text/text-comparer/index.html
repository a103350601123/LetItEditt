How to use Text Comparer / Diff

  1. Paste the original text on the left or open a text file for that side.
  2. Paste the changed text on the right or open a second file.
  3. Choose lines or words, then review highlighted additions and removals.

In-depth guide

How the diff is calculated

Both sides are split into lines or words and compared with a longest-common-subsequence algorithm. Unchanged units are shown with a leading space, additions with a plus sign and removals with a minus sign. The summary counts added and removed units so you can see the size of the change at a glance.

The output is rendered with text nodes inside safe elements, so markup in either input is displayed as text and never executed. Each side can be swapped, cleared or filled from its own file input, which makes it practical to review two versions of a document without a separate editor.

Text only, and a firm size limit

This tool compares text, not formatting. A DOCX upload is opened as a ZIP archive in the browser and its paragraph text is extracted; tables, columns, headers and styling are outside the comparison. The status line states this explicitly so nobody mistakes the result for a visual track-changes view.

A full LCS comparison grows with the product of the two input sizes, so each side is capped at 1,200 units. Larger inputs return a clear error rather than freezing the page. PDF and legacy .doc files are rejected because reliable extraction would require a parser this local tool does not ship.

Frequently asked questions

How large a text can I compare?

Up to 1,200 lines or words per side. Larger inputs show a clear error instead of freezing your browser.

Does it compare document formatting?

No. Only extracted text is compared. DOCX uploads provide paragraph text; tables, columns and styling are not part of the comparison.

Can I compare a PDF?

No. PDF text extraction would require a layout-aware parser, so PDF and legacy .doc uploads are rejected with an explanation rather than guessed at.
