How to use Text Filter

  1. Paste the source text.
  2. Type comma-separated words to highlight and words to remove.
  3. Click Apply Filter. Yellow highlights and removals appear in the output.
  4. Copy the plain output text when you are done.

In-depth guide

Order of operations

Every removal term is applied to the working text in the order typed, followed by every highlight term. Because the passes are sequential, a later removal can act on text changed by an earlier one.

Matches are case-insensitive and use word boundaries. The original input text is never trimmed, and empty comma-separated terms are ignored.

Frequently asked questions

Is highlighting safe?

Yes. The reference tool writes output with innerHTML, which can execute markup from pasted text. This build creates highlight spans and text nodes directly, so no input HTML is interpreted.

Does it match phrases or partial words?

Terms are wrapped in word boundaries and escaped, so only whole words match. A term beginning or ending with punctuation or a non-ASCII letter may not match at those edges.

What happens to spacing after removal?

Only the matched word is removed. Surrounding spaces stay exactly as they were, so double spaces can remain.
