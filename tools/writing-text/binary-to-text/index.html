Binary to Text Converter

Paste binary groups such as 01000001 01000010 to get AB. Invalid groups are reported, never silently ignored.

How to use Binary to Text Converter

  1. Paste 8-bit binary groups separated by spaces.
  2. Text is decoded automatically.
  3. Copy the decoded text.

Example

Input
01000001 01000010
Output
AB

Frequently asked questions

What if I paste continuous binary with no spaces?

The tool will report that groups must be 8 bits. Add spaces between each byte.
