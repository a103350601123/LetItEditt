In-depth guide

What counts as a link

The extractor looks for explicit http and https URLs, www-prefixed addresses and bare domains with a sensible suffix. Each candidate is trimmed of surrounding punctuation and validated before it is kept, so a sentence ending in a period does not produce a broken link. Results are de-duplicated in the order they first appear, which makes it easy to compare a pasted block with a source list.

Schemes other than http and https are deliberately ignored. A mailto: address is an email, not a web link, and javascript: values are never emitted, which keeps the output safe to paste into a document or a browser address bar.

Files, privacy and limits

Text-like files such as TXT, CSV, TSV, Markdown, JSON and HTML are read directly. DOCX files are opened as ZIP archives in the browser and the paragraph text is scanned from the document XML; if raw decompression is unavailable, the tool explains how to save the file as text instead.

Everything runs on your device. No URL is fetched, followed or resolved, so the tool never contacts the sites it finds. Only links written in the input are reported; links hidden behind shortened redirects or generated by scripts cannot be recovered from pasted text.

Frequently asked questions

Does it remove trailing punctuation?

Yes. A final period, comma, closing bracket or quote is not included in the URL.

Which link forms are recognised?

Full http and https URLs, www. addresses and bare domains with a public-style suffix. mailto: and javascript: values are ignored because they are not web URLs.

Can it read a Word document?

DOCX files are read locally where the browser supports decompression and only their text is scanned. PDF and legacy .doc files are rejected with an explanation.
