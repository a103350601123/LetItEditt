How to use Text Redactor

  1. Paste text or load a plain-text file, then choose which categories to hide.
  2. Choose labels, realistic fake values or black bars, and add any custom words to hide.
  3. Copy the redacted text and paste it into another service only if you are comfortable doing so.
  4. Paste that service’s reply into step 3 and restore the original values using the in-memory key or a saved key file.

In-depth guide

How labels stay consistent

Detected values are normalised so the same email, phone number or secret always receives the same label within one session. Overlapping matches are resolved by priority, length and position, and custom words are expanded to align with detected spans.

Restoration replaces bracketed labels and bare labels from the key. Fake values are mapped back as well; unknown labels are reported and left unchanged.

Limits and safety

The reference tool caps uploads at 20 MB and internal scanning at one million characters, with lower caps for highlighted paths. This build applies a 5 MB upload limit for responsiveness.

Redaction reduces risk but cannot guarantee privacy. Check the output for anything the detectors missed, and remember that any service you paste redacted text into receives the redacted version, not the original.

Frequently asked questions

Is redaction the same as anonymisation?

No. Detection is heuristic, and writing style or context can still identify someone. Always review the redacted text before sharing it.

Does this tool send my text anywhere?

No. Detection, replacement and restoration happen in your browser. This tool makes no network requests.

What is inside a saved key?

The key contains the original values for every label. Treat the file as sensitive, store it privately and delete it when you no longer need it.

Can black bars be restored?

No. Black-bar mode is irreversible because the original characters are not written into the text. Use labels or fake values when you need restoration.
