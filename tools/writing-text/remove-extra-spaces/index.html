In-depth guide

One simple rule

This tool applies one regular expression: every sequence of whitespace characters becomes a single space, then the outer ends are trimmed. That includes ordinary spaces, tabs, carriage returns, line feeds and less common Unicode spaces.

It is deliberately simpler than Text Cleaner. If you need to remove blank lines but keep paragraphs, or convert spaces to tabs, use the full cleaner instead.

Frequently asked questions

Does it keep line breaks?

No. The reference rule collapses all whitespace into one space, so newlines and paragraphs are removed. Use Text Cleaner for options that preserve lines.

Does it trim the start and end?

Yes. After collapsing whitespace, leading and trailing spaces are removed.

Is there a file size limit?

Files larger than 5 MB are rejected so the page stays responsive. Text is read locally in your browser.
