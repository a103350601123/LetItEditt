Free file converter

The LetItEdit file converter changes PDF, Word and Excel files into other formats in your browser.

Open the file converter

What you can do

  • PDF to Word, Excel, text, web page, PNG or JPG
  • Word to PDF, text, web page or Excel tables
  • Excel and CSV to PDF, Word, CSV, web page, ODS, XLS, XLSX or text
  • Headings, paragraphs and tables are rebuilt so the text reads cleanly

How to use it

  1. Open the file converter and choose a file.
  2. Choose the format to convert to.
  3. Press Convert and download.

Frequently asked questions

Is the converted text clean?

PDF text is rebuilt into headings, paragraphs and tables. Complex layouts can still need a quick check.

Can it convert a scanned PDF?

Scanned PDFs have no text. Use the text extractor on a picture of the page.

Can I convert Word to PDF?

Yes. The PDF looks like the document, but the text is not selectable.
