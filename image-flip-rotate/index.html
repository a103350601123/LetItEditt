How to use Image Flip & Rotate

  1. Open a PNG, JPG or WebP image from your device.
  2. Choose horizontal or vertical flip to mirror the picture.

  4. Combine flips and turns until the orientation looks right.

In-depth guide

What flipping and rotating change

Flipping and rotating are orientation fixes, not content edits. A flip mirrors the picture across an axis, while a rotation moves every pixel around the centre. This tool performs both locally: you open a file, choose the operations, watch the preview and download a new image. It is useful for photos from phones, scanned pages, screenshots and design assets that arrived the wrong way round. Because the work happens in the browser, there is no upload and no waiting for a remote service. The controls are deliberately simple, so you can correct orientation in a few clicks without opening a full image editor or learning layers, masks and selection tools. Undoing a step is as simple as pressing the opposite control.

Quarter turns and dimension swaps

A quarter turn moves the top edge to the side, so 90 and 270 degree results swap the width and height of the canvas. Two turns give a 180 degree result and keep the original dimensions. Each step is exact: there is no interpolation and no resampling, so the number of pixels stays the same and edges remain sharp. You can turn clockwise or counterclockwise and apply as many steps as you need, because four quarter turns return the image to its starting orientation. Watch the preview after each click; if you overshoot, keep turning rather than trying to undo a resizing operation elsewhere. Keep track of the count if you plan to return to the original angle.

Horizontal and vertical mirrors

A horizontal flip mirrors left and right, which is handy for fixing selfies saved backwards or matching a logo that faces the other way. A vertical flip mirrors top and bottom, useful when a scan or a texture came out inverted. Mirrors do not swap canvas dimensions. Text becomes reversed, so a flipped screenshot will no longer read correctly; that is expected behaviour rather than a bug. If you are preparing a design element, check that any lettering, arrows or logos still face the intended direction before you download. For photographs without text, a mirror is often the quickest way to fix composition. Mirroring twice in the same direction simply restores the first view. Check the edges of the frame as well as the centre.

Combining operations

Flips and turns can be combined in any order. A photo that is upside down and mirrored can be corrected with one quarter turn and one horizontal flip. The controls apply each operation to the current preview, so stacking them works naturally and you can keep clicking until the orientation is right. There is no history list here, so if you go too far, repeat the opposite operation or reopen the source file and start again. Combine orientation fixes before other edits: once you crop or resize, the relationship between edges changes and it becomes harder to judge which way is up. Write down the sequence you used so you can repeat it on similar photos.

Formats and image quality

Downloads are available as PNG, JPG or WebP. PNG keeps lossless pixels and transparency, WebP gives smaller files while supporting transparency, and JPG is widely compatible but uses lossy compression. A 90 degree rotation only rearranges existing pixels, so the rotation itself does not soften the picture. Any change in sharpness comes from re-encoding, especially when saving a PNG as JPG, or from later resizing. To keep the best quality, export once in the format you need and avoid repeatedly opening and saving the same file. Check the preview at full size before downloading a large photo. A downloaded JPG cannot later be turned back into the exact PNG you started with. Choose the format before you leave the page.

Limits, privacy and fixes

This tool does not rotate by arbitrary angles, straighten a tilted horizon, crop edges or correct perspective. It also does not edit camera orientation tags; it writes a fresh image from the pixels you see, so an exported file should look correct without depending on metadata. All processing is local and nothing is uploaded, although a shared screen or a file left in a download folder can still reveal an image you meant to keep private. If a preview looks blank, wait for a large file to finish decoding, then try a smaller copy. If the result still appears sideways, confirm you applied a turn rather than a mirror and open the downloaded file directly.

Frequently asked questions

Does the photo leave my device?

No. Flipping and rotating are done in your browser with the file you open. Nothing is uploaded, and the image is discarded when the page is closed.

Does rotating reduce image quality?

A 90-degree rotation is a pixel rearrangement, so the rotation itself loses no detail. Quality can change when the result is encoded to JPG, which is lossy, or resized. Choose PNG or WebP to avoid JPG re-encoding artifacts.

Can I rotate by any angle, such as 17 degrees?

No. This tool turns images in 90-degree increments only. It does not do free-angle rotation, perspective correction or straightening of a tilted horizon.

Will camera orientation metadata be handled?

The preview uses the pixels as opened. The exported file is a fresh image without the original rotation tag, so check the visible result before downloading instead of relying on metadata.

Why does my export look blank or still sideways?

Very large files can take time to draw, so wait for the preview before downloading. If the photo still appears sideways, confirm you applied a quarter turn rather than a mirror, and open the downloaded file instead of a cached thumbnail.
