Free online Word (DOCX) editor

The LetItEdit Word editor opens a .docx file with its page layout and lets you change it in your browser. It is useful when you do not have Microsoft Word.

Open the Word editor

What you can do

  • Open a .docx file with its layout
  • Change font, font size, text colour, highlight and line spacing
  • Use headings, bold, italic, underline, lists, alignment and indents
  • Insert tables, pictures, links and page breaks
  • Download as .docx, or print and save as PDF for an exact copy

How to use it

  1. Open the Word editor and choose a .docx file.
  2. Click in the page and use the formatting bar.
  3. Press Download .docx, or Print or save as PDF.

Frequently asked questions

Does it keep my formatting?

The page opens with its layout. A downloaded .docx is a best effort copy, so use Print or save as PDF when you need an exact copy.

Which fonts can I use?

The list includes Calibri, Cambria, Arial, Times New Roman, Georgia, Verdana and more. A font shows on screen only if it is installed on your device.

Can it open old .doc files?

No. Save them as .docx first.
